# Kimi WebBridge

让 AI 直接操控你的浏览器：打开网页、点击按钮、填写表单、阅读页面、截图、把网页保存为
PDF——全部发生在你自己的浏览器里，用的是你已登录的账号，无需把密码交给任何人。

AI 干活全程看得见：它处理的每个任务都会在浏览器里聚成一个带任务名的标签组，正在看哪些
页面、做到哪一步一目了然；任务结束后一键收起。

## 使用前提

需配合 **Kimi WebBridge 浏览器扩展**一起使用。安装与说明见官网：

- 中文：https://www.kimi.com/zh-cn/features/webbridge
- English：https://www.kimi.com/features/webbridge
