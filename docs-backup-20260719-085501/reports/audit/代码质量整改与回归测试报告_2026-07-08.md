## 二、整改明细

### 1. `audit:hardcode.ts` — P0 静默回退降级（非阻塞）
- `scan()` 中新增：`blockingViolations = violations.filter(f => f.category !== '静默回退')`，`summary.totalViolations` 仅计阻塞级（Fatal/Critical/Major 真实硬编码），新增 `summary.totalWarnings`。
- `formatReport()` 输出区分「阻塞级违规(驱动门禁)」与「非阻塞警告(静默回退等)」。
- 文件头退出码注释同步更新：仅真实硬编码驱动退出码 1。
- **效果**：原 59 处静默回退不再阻塞合并；HEX 颜色 / 魔法数字 / URL / 超时 / 股票代码 仍正常拦截。

### 2. `quality-gate-check.cjs` — P1 启发式误报修复
- **G4 event-listener-cleanup**：`hasCleanup` 增加 `unregister` / `dispose` / `off(` / `cancel` / `disconnect` / `subscribeRef` / `.current()` 识别，正确判定 MarketDataProvider 等"订阅返回值清理"范式。
- **G3 ui-hardcoded-colors**：跳过 `*.test.ts(x)` 与 `__tests__` 目录；`isTokenDefFile` 扩展为忽略大小写匹配 `color|token|palette` 文件名（如 `statusColors.ts`）。

### 3. `../../../AGENTS.md` — P2 数字对齐 + 枚举补全
- `src/services/` 注释：`20个子域` → `21个子域`，枚举尾部补 `rbac(权限)`。
- `src/store/` 注释：`47个Zustand Store` → `49个Zustand Store`。

### 4. `../../explanation/03-architecture-standards.md` / `../../reference/data-definition.md` — P1 Major RBAC 文档补录
- `../../explanation/03-architecture-standards.md` 新增 **§8 权限与 RBAC 子系统（v24）**：设计意图、服务子域、6 表映射、7 个 ENVELOPE_ACTION 写入通道、ACL_MATRIX 注册、append-only 审计原则。
- `../../reference/data-definition.md` 新增 **§7 RBAC 权限子系统数据实体**：6 张表逐字段（取自 `src/types/modules/rbac.types.ts`：UserEntity / RoleEntity / PermissionEntity / UserRoleMapping / RolePermissionMapping / PermissionAuditLog）。

### 5. `audit-hardcode.test.ts` — 断言同步
- 将 `expect(output).toContain('问题总数: 0')` 更新为 `expect(output).toContain('阻塞级违规(驱动门禁): 0')`，与 P0 新输出文案一致。
