## 二、V9 现有能力 vs 外部系统 差距分析

### 2.1 V9 现有优势（对方不具备）

### 2.2 V9 关键短板（对方具备而 V9 缺失/薄弱）

| 缺失因子 | 对方表现 | V9 现状 | 差距等级 |
|----------|----------|---------|----------|

| **确赔率概率输出** | 74%/100%/30% 可量化概率 | 有 winRateScore 但非概率化输出 | **P1 高优** |

| **动态异动监控** | 个股异动实时推送 | 无独立服务 | **P3 增强** |

### 2.3 根因诊断

外部系统的本质设计哲学是 **「评分→信号价→执行」完整闭环**：

```
抽象评分(91分) → 信号价(13.61元) → 交易计划(买/损/盈/加仓) → 确赚率(74%)
     ↓                ↓                    ↓                      ↓
  "这只票好"    "什么价买"          "怎么操作"             "多大把握"
```

V9 的现状是 **「评分→信号→...断链」**：

```
V6评分(3.7分) → strong_buy信号 → [???] → [???]
     ↓                ↓
  "这只票好"      "建议买入"     (无精确价位)  (无概率估计)
```

**执行层的转化链路缺失是最大短板。**

## 三、体系化提升方案

### 3.1 P0：信号价机制（紧急）

**目标**：实现类似截图的精确触发价位计算。

**设计方案**：
```
新增文件: src/services/scoring/v6-engine/calculators/signalPriceCalculator.ts

输入:
  - 当前价格 (currentPrice)
  - 回踩目标均线 (MA20/MA60)
  - 回踩深度百分比 (dipDepth%, 从 l7_l8.ts 的 BIAS/PAS 推导)
  - K线支撑位 (近期低点/前复权价)
  - 波动率 (ATR14 或 20日振幅)

输出: SignalPrice {
  entryPrice: number,       // 信号价（如 49.25）
  stopLossPrice: number,    // 止损价
  takeProfitPrice: number,  // 止盈价
  addPositionPrice: number, // 止盈加仓价
  confidence: number,       // 触发置信度 0~1
  rationale: string         // 定价理由
}

算法核心:
  signalPrice = MA_support × (1 - dipDepth%) ± ATR_adjustment
  其中 dipDepth% 由历史回测最优参数确定（建议初始值 2%~5%）
```

**改造点**：
- `l7_l8.ts` 的 `golden_buy` 输出增加 `signalPrice` 字段
- `buySellPointConfig.ts` 的 `buy_dip` 增加 `signalPriceCalc` 开关
- `rotationSignalDetector.ts` 输出的 `Signal` 结构扩展支持四档价位

### 3.2 P1-A：确赚率估算模型（高优）

**目标**：输出「确赚率 XX%」的可量化成功概率。

**设计方案**：
```
新增文件: src/services/scoring/probabilityEstimator.ts

贝叶斯框架:
  P(盈利 | 当前因子组合) = 
    Σ P(因子i=当前值 | 历史盈利) × P(历史盈利) / P(因子i=当前值)

先验概率来源:
  1. 同策略历史回测胜率 (backtestWinRate)
  2. 当前因子共振度 (resonanceScore = 命中策略数 / 总策略数)
  3. 市场状态 (marketRegime: 牛/震荡/熊)
  4. 标的自身特性 (波动率/流动性/市值)

后验修正:
  - E4评级为"注意"时，概率 × 0.7 折扣
  - 新增风险标签每项 × 0.9 折扣
  - 人气排名 Top 20 时，流动性溢价 × 1.05

输出: { probability: 0.74, confidenceInterval: [0.65, 0.82], factors: [...] }
```

### 3.3 P1-B：TD 九转择时集成（高优）

**目标**：在趋势择时技能中补充 TD Sequential。

**设计方案**：
```typescript
// 在 trendTechnicalTimingSkill.ts 中新增:

function calculateTDSequential(closes: number[]): TDResult {
  // TD Buy Setup: 连续9根收盘价 < 4根前的收盘价
  // TD Buy Countdown: Setup后计数至13
  // 完整信号: Setup(9) + Countdown(13) = TD9 Buy / TD13 Buy
  
  let setupCount = 0;
  let countdownCount = 0;
  let inSetup = false;
  let inCountdown = false;
  
  for (let i = 4; i < closes.length; i++) {
    if (closes[i] < closes[i - 4]) {
      if (!inSetup) inSetup = true;
      setupCount++;
      if (setupCount >= 9 && !inCountdown) {
        inCountdown = true;
        countdownCount = 1;
      } else if (inCountdown) {
        countdownCount++;
      }
    } else {
      if (inSetup && setupCount < 9) { setupCount = 0; inSetup = false; }
    }
  }
  
  return { setupComplete: setupCount >= 9, countdown: countdownCount, signal: ... };
}
```

**集成点**：在 `determineSignal()` 中增加分支：
- TD9 + ADX > 25 → `strong_buy` (置信度上调 0.05)
- TD13 + RSI < 30 → `golden_buy` (极端超卖反转)

### 3.4 P2：多策略共振标签系统（中优）

**目标**：每只标的显示命中哪些策略标签及共振数量。

**设计方案**：
```
新增文件: src/services/scoring/strategyTagRegistry.ts

标签定义 (参考截图顶部筛选栏):
  - 金蛋N: 高确定性机会
  - 多策略共振: ≥2个策略同时命中
  - 黄金坑: 超跌反弹型
  - 二波启动: 第二波上涨
  - 主强理: 主力强势逻辑
  - 产业链卡点: 供应链关键节点
  - 分线回踩vN: 均线回踩型
  - 二次突破: 前高突破确认

打标流程:
  各策略引擎(HotSectorAnalyzer/ValuePitAnalyzer/RotationSignalDetector/
  SignalPriceCalculator) 输出时附带 tags: string[]
  → strategyTagRegistry.aggregate(tags[]) → 去重排序 → 前端展示
```

### 3.5 P2：事件日历驱动因子（中优）

**目标**：未来 N 日事件自动加权评分。

**数据源**：
- 财经日历 API（财报日期/股东大会/限售解禁/分红除权）
- 公告爬取（重大合同/重组/减持）

**加权逻辑**：
```
eventScoreAdjustment = 
  case 财报前3日内: +0.15 (波动率放大，高风险高收益)
  case 财报前3~10日: +0.05 (预期博弈期)
  case 股东大会当日: -0.03 (不确定性小幅折价)
  case 限售解禁当日: -0.10 (抛压预期)
  default: 0
```

### 3.6 P3：人气排名 + 动态异动监控（增强）

**人气排名**：接入行情数据的个股关注度指标（搜索量/自选加仓率/讨论热度），全市场排序。

**异动监控**：
```
anomalyMonitor.detect(stockId): AnomalyAlert[] =
  - 振幅突变: 当日振幅 > 20日均振幅 × 2.5
  - 量比突变: 当日量比 > 5 且价格未同步
  - 主力资金异常: 单日净流入 > 5日均值 × 3
  - 连板/跌停: 连续涨/跌停板计数
```

## 五、V9 不应照搬的部分

| 对方特征 | 建议 | 理由 |
|----------|------|------|
| 单策略依赖（仅分线回踩） | 保持双策略+轮动多路径 | 降低单策略失效风险 |
| 固定组合上限（30%/22%） | 已有更精细的双轨资金管理 | V9 方案更优 |
| 缺乏基本面深度 | 保持 V6 11 层引擎不变 | 这是 V9 核心护城河 |
| E4 评级黑箱 | 改用可解释的市场状态因子 | 避免「信任我但不告诉你为什么」 |
