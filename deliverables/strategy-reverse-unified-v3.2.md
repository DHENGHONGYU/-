## 三、五步法因子拆解（逆向推断）

| 步 | 因子       | 量化条件                             | 权重推断         |
| - | -------- | -------------------------------- | ------------ |
| 1 | 主升浪识别    | 60日涨幅>50% 或 20日涨幅>30%            | 入门Gate（必要条件） |
| 2 | 放量突破     | 主升期间量比>5倍（≥1-3天）                 | 强过滤（剔除假突破）   |
| 3 | 分级回踩     | 回踩至5/10/20日线附近缩量止跌；强度 5日>10日>20日 | 核心买点判定       |
| 4 | 试盘/二波    | 放量长上影(试盘) 或 放量突破前高(二波)           | 触发确认         |
| 5 | MAS宽度+分批 | MAS动能>+5pp 加分；盈+10%减1/3；损-5%     | 加仓/退出纪律      |

**关键语义修正**：

- "缩强" = 缩量强势回踩（健康回调，非派发）
- "分级" = 按回踩触及的均线层级（5/10/20）分档，层级越短越强
- 长上影不再是见顶信号，而是**试盘**（主力试探抛压），属利好

### 5.2 厘清：用户个人"逆势强势股筛选法" vs V9 引擎

源B对比表显示用户自有方法：

```
目标：刚启动 + 量价配合
买点：早盘逆势 + 均价线支撑
持仓：短线（快进快出）
信号：MACD零轴上 + 量比>1.5
```

这与 V9 的 `golden_buy`（换手5-10%+量比>5+低位价涨）部分重叠但不等同——用户个人法是**早盘逆势短线**，V9引擎是**机构级多因子**。二者是不同的战术层。
