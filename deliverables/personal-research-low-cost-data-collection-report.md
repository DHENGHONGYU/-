## 一、执行摘要

针对 FinSightV9 个人研究场景，本报告在**年成本 ≤ 500 元**的硬约束下，调研了开源库、免费 API、共享平台、券商量化通道、低付费 API 共 5 大类方案。核心结论：

1. **完全零成本即可跑通 8 个维度中的 6 个**：东方财富公开端点 + AkShare + Baostock + 腾讯/新浪行情，足以覆盖 01-06 和 08 的基础数据。
2. **500 元/年预算可显著提升稳定性**：Tushare Pro（500 元/年，5000 积分）能解锁「无上限日线 + 特色数据 + 公告/研报/龙虎榜」，是性价比最高的"稳定增强包"。
3. **券商量化通道（QMT/PTrade）是隐藏免费数据入口**：10 万资产门槛即可开通，内置行情/分钟数据，但数据难以导出到外部系统。
4. **OpenBB 社区版 + QVeris 是 AI Agent 集成友好选项**：适合个人研究者，但 A 股深度不如本土工具。

**推荐组合**：
- **零成本方案（0 元/年）**：东财公开端点 + AkShare + Baostock + 腾讯直连
- **增强方案（500 元/年）**：零成本方案 + Tushare Pro 5000 积分
- **AI 集成方案（~200 元/年）**：零成本方案 + Kimi 会员（用于摘要/分析）

|------|------|------|---------|---------|---------|

## 四、三套推荐方案（按成本性排序）

### 方案 A：零成本全能方案（0 元/年）

**组合**：东方财富公开端点 + AkShare + Baostock + 腾讯/新浪直连

**适用人群**：预算为零、能容忍一定维护成本、以研究和回测为主

**优点**：
- 完全免费，无授权门槛
- 覆盖 8 个维度 80% 以上需求
- 东财端点已验证可用（P1 接入准备中）

**缺点**：
- AkShare 爬虫不稳定，需持续修复
- 无 SLA，数据质量需自行校验
- 缺少实时 Level-2 和分钟数据

**维护成本**：每月 0.5-2 人天（处理接口变更）

### 方案 B：500 元稳定增强方案（500 元/年）

**组合**：方案 A + Tushare Pro 5000 积分（约 500 元/年）

**适用人群**：需要稳定日线数据、希望减少爬虫维护、有 500 元年预算

**优点**：
- Tushare Pro 数据标准化好，除权除息已处理
- 常规日线接口几乎无频次限制
- 特色数据包含筹码、龙虎榜、券商金股、研报评级
- 比方案 A 显著降低维护成本

**缺点**：
- 分钟级数据需额外 1000 元/月（不在 500 元预算内）
- 部分高级接口需单独开通权限

**维护成本**：每月 0.2-0.5 人天

### 方案 C：AI 增强研究方案（~200 元/年）

**组合**：方案 A + Kimi 会员（199 元/月，已开通）

**适用人群**：希望用 AI 辅助解读公告、新闻、研报、行业关联

**优点**：
- 利用已开通的 Kimi 会员
- 适合 04/05/07/08 的智能摘要和交叉分析
- 不需要额外数据采购

**缺点**：
- Kimi 输出非结构化，需结果解析和置信度校验
- 不能替代量化原始数据

**维护成本**：每月 0.3 人天（解析器迭代）

## 五、与 M4 多源聚合方案的融合建议

将上述低成本方案纳入 FinSightV9 的 M4 多源聚合架构，建议按以下层级设计：

```
┌─────────────────────────────────────────────────────────────┐
│  FinSightV9 数据采集层（M4 多源聚合）                          │
├─────────────────────────────────────────────────────────────┤
│  L1 公开直连（0 元）                                          │
│  腾讯行情 / 新浪行情 / 东方财富公开端点                          │
├─────────────────────────────────────────────────────────────┤
│  L2 开源工具（0 元）                                           │
│  AkShare / Baostock / efinance（本地 Python 服务）            │
├─────────────────────────────────────────────────────────────┤
│  L3 低付费稳定源（≤ 500 元/年）                                │
│  Tushare Pro 5000 积分                                         │
├─────────────────────────────────────────────────────────────┤
│  L4 会员/AI 分析层（已开通）                                    │
│  Kimi 会员 → 摘要/分析/关联解读                                 │
├─────────────────────────────────────────────────────────────┤
│  L5 商业兜底（未来可选）                                        │
│  iFinD MCP（资讯类兜底）                                        │
└─────────────────────────────────────────────────────────────┘
```

**推荐优先级**：
1. **立即采用方案 A**：0 成本接入东财/AkShare/Baostock，覆盖 80% 需求。
2. **同时评估方案 B**：用 Tushare Pro 500 元/年替换部分 AkShare 不稳定接口，降低维护成本。
3. **激活方案 C**：利用已开通 Kimi 会员做资讯摘要，不增加数据采购成本。
4. **保留 iFinD MCP 作为 P2 商业兜底**：当 04/05/06/08 维度稳定性不达标时，以机构名义采购。

## 六、成本性四维度评估

| 维度 | 评估项 | 当前状态 | 采用方案 A 后 | 采用方案 B 后 |
|------|--------|---------|--------------|--------------|
| **完整性** | 8 维度字段覆盖 | ★★ | ★★★★ | ★★★★★ |
| **精确性** | 数据标准化/除权除息 | ★★ | ★★★ | ★★★★ |
| **及时性** | 日线/公告/新闻更新 | ★★ | ★★★ | ★★★★ |
| **成本性** | 年成本/维护成本 | ★★★★★（0 元但高维护） | ★★★★（低采购成本） | ★★★★（500 元/年 + 低维护） |

**结论**：在 500 元/年预算内，**方案 B 是成本性最优解**——以较低成本换取显著稳定性与精确性提升，同时保留方案 A 作为免费备份。

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|---------|
