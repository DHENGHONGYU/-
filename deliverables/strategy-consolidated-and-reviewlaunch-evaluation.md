## 1.2 五步法因子链（逆向推断）

| 步 | 因子 | 量化条件 | 性质 |
| - | -------- | -------------------------------- | ------------ |
| 1 | 主升浪识别 | 60日涨幅>50% 或 20日涨幅>30% | 入场 Gate（必要） |
| 2 | 放量突破 | 主升期间量比>5倍（≥1-3天）；缩量突破=假突破剔除 | 强过滤 |
| 3 | 分级回踩 | 回踩 5/10/20 日线缩量止跌；强度 5日>10日>20日 | 核心买点 |
| 4 | 试盘/二波 | 放量长上影(试盘) 或 放量突破前高(二波) | 触发确认 |
| 5 | MAS宽度+分批 | MAS动能>+5pp 加分；盈+10%减1/3；损-5% | 纪律 |

**关键语义**：「缩强」=缩量强势回踩（健康回调）；「分级」=按回踩触及均线层级分档，层级越短越强；长上影=试盘（利好，非见顶）。

# 第二部分：新增 — 复盘启动分析关键页面 + 独立评价体系

## 2.1 为什么需要"独立评价体系"

V9 现有三层评分彼此职责不同，但**缺一层"复盘启动就绪度"**：

| 层 | 现有组件 | 回答的问题 | 缺什么 |
|----|----------|-----------|--------|
| 基本面 | V6 引擎 11层（`IntelligentScorePage`） | 这只票**值不值得拥有**？ | — |
| 交易信号 | `golden_buy`(l7_l8) / 板块轮动 | **现在该不该买**？ | — |
| **复盘启动（新）** | **RLES 评价体系** | **此刻该不该为它投入复盘精力？** | 这一层不存在 |

> 倒推结论直接支撑本设计：源B 中**新华制药因"数据不全"被压到 53.7**——这正是"数据就绪度门禁"的实证；紫光因风险标记被砍仓——正是"风险否决权"的实证。RLES 把这两类规则**显式建模为独立评价层**，与 V6（价值）、golden_buy（信号）彻底解耦。

## 2.2 评价体系设计：RLES 四维评分卡

**RLES = Review Launch Evaluation System（复盘启动评价体系）**，四维独立评分 0–100：

| 维度 | 名称 | 计分内容 | V9 数据来源 |
|------|------|----------|-------------|
| **D1** | 数据就绪度 | 行情/K线、财务、筹码、资讯四源完整度 | 各采集器 freshnessGuard / `intelligentScoreStore` 维度就绪 |
| **D2** | 策略适配度 | 双策略分流判定（热门板块 V6>3.5 / 价值洼地 2.8-3.5）、板块景气、市场风格契合 | 板块轮动五因子 F1、双策略 gate |
| **D3** | 时机成熟度 | 主升浪二波检测、分级回踩、golden_buy、TD九转+逆势抗跌、MAS宽度 | `secondWaveDetector`(新)、`l7_l8`、`trendTechnicalTiming`、`breadthFactor`(新) |
| **D4** | 风险健康度 | 新增风险标签、市场风险评级、三条禁令、仓位乘数预览 | `riskPositionMultiplier`(新)、`audit:acl-consistency` 禁令 |

## 2.3 计算公式 + 风险否决 + 分级分流

```
# D1 作为置信乘子（质量门，不参与加权）
conf(D1) = 1.00  if D1 ≥ 80
         = 0.85  if 60 ≤ D1 < 80
         = 0.60  if D1 < 60          # 对标新华制药"数据不全"保守评分

# D2/D3/D4 加权（时机最 actionable，风险保护性最高）
base   = 0.25·D2 + 0.40·D3 + 0.35·D4
final  = base × conf(D1)

# 风险否决（命中硬风险任一项 → 砍仓折扣，对齐紫光 22%/30%≈0.73）
if 新增风险100% ∨ 三条禁令触发 ∨ E4/MAS 市场降级:
    final ×= 0.73
    打标 "风险降级"

# 分级分流（复盘就绪结论）
final ≥ 80 且 D1 ≥ 80  → 「优先深度复盘」(绿)
60 ≤ final < 80        → 「常规复盘」   (黄)
final < 60 或 D1 < 60  → 「谨慎复盘·建议补齐数据/规避」(橙红)
```

**设计原则**：权重可解释（对方单综合分不公开权重，我们反其道）；D1 守质量底线、D4 守风险底线，二者都对结论有"否决/折扣"权，而非简单相加。

## 2.6 与逆向策略的衔接（消费新缺口组件）

RLES 是**元层**，直接消费第一部分识别出的 V9 缺口组件：

- **D3 时机成熟度** 直接依赖 `secondWaveDetector`（缺口①）与 `breadthFactor`（缺口②）——这两个组件落地后，RLES 才能完整评分；在此之前 D3 子项可降级为"待接入"。
- **D4 风险健康度** 直接依赖 `riskPositionMultiplier`（缺口⑥）——对齐紫光 0.73 砍仓语义。
- **D1 数据就绪度** 直接解释"新华制药 53.7 数据不全"现象，把对方的隐性惩罚变为 V9 显式可解释门禁。
