## 一、逐股倒推表

### 1. 腾龙股份 (300534) — 结论分 91.0（最高）

| 呈现结论 | 倒推因子 | 策略语义 |
|----------|----------|----------|
| 信号价 13.61 / 组合上限 30% / E4正常 | 标准风险敞口 | 无风险标签 → 给满仓上限，无折扣 |
| 主要原因①：强势分线回踩确认 | **核心 Gate** | 入场必要条件，三标的共有 |
| 主要原因②：分线日大重 14.8亿 | 量能因子（正向） | 中小盘回踩日放量 = 主力承接吸筹 |
| 主要原因③：长上影 | 趋势动能（特殊语义） | 前高试盘上影 → 回踩即二次蓄势买点（被解读为利好） |
| 破赚率 30% | 待复核指标 | 数值偏低却未拖累高分 → **非主导因子** |

**倒推结论**：腾龙拿满分的关键在于"干净"——无风险标记 + E4正常，且长上影被该策略解读为"试盘后回踩"而非见顶。其核心因子（回踩确认+量能）纯度最高。

### 2. 万邦医药 (301520) — 结论分 86.0

| 呈现结论 | 倒推因子 | 策略语义 |
|----------|----------|----------|
| 112%强势 / 突破涨停 | 趋势动能（动量） | 60日强动量 + 近期涨停突破 |
| 分线日大重 11.2亿 | 量能因子 | 与腾龙同级 |
| 投资动态：金牌鉴股 当月+26% | 情绪/第三方背书 | 动量外部确认（社会证明） |
| 事件：08-29 财报 | 事件因子（中性偏正） | 财报前博弈窗口 |
| 组合上限 30% / E4正常 | 标准风险敞口 | 无风险标记 |

**倒推结论**：万邦的差异化因子是"60日涨幅/突破涨停"——策略对高动量股也认可回踩买点，且引入第三方荐股作为动量确认。次要因子从腾龙的"长上影"切换为"60日涨幅"，说明**次要因子自适应**。

### 3. 紫光股份 (000938) — 结论分 74.0（最低）

| 呈现结论 | 倒推因子 | 策略语义 |
|----------|----------|----------|
| 分线日巨量 190.6亿 | 量能因子（**语境反转**） | 大盘股回踩日天量 = 派发/见顶风险，非承接 |
| 人气 #7 | 人气因子 | 高热度但未抵消风险 |
| 幅度 79.0% / MA5变化 +6.78pp | 趋势动能 | 近期加速，但已处高位 |
| 新增风险 100% | **风险否决因子** | 触发惩罚 |
| E4评级 注意 | 市场风险因子 | 市场状态降级 |
| 组合上限 22%（vs 30%） | 风险仓位乘数 ≈0.73 | 风险标记 → 砍仓 27% |

**倒推结论**：紫光揭示了策略的"**风险否决权**"——即便天量(190.6亿)+人气#7，新增风险100%+E4注意直接将评分压到最低并砍仓。同一"巨量"在中小盘是利好、在大盘是利空，说明**量能因子带语境权重**（市值规模参与判定）。

## 三、对 V9 的精化建议（基于本次校对）

1. **引入风险仓位乘数**：V9 已有 audit:acl-consistency 三条禁令，但缺少"风险标签→仓位折扣"映射。建议新增 `riskPositionMultiplier` 表（对标紫光 22% 逻辑）。
2. **量能语境判断可直接复用 V9 筹码体系**：八级筹码 PAS/BIAS/PRO 已能区分吸筹与派发，可直接支撑"大盘放量=派发"的语境判定，无需另起炉灶。
3. **次要因子自适应展示**：V9 的 V6 引擎输出因子很多，但前端应学习对方的"只亮最显著因子"做法，避免信息过载。
4. **第三方荐股/人气作为情绪面补充**：可作为 V9 情绪面评分的补充数据源（万邦案例证明有效）。
5. **核心 Gate 对应 V9 双策略的入选门槛**：保持"热门板块 V6>3.5 / 价值洼地 2.8-3.5"作为不可省门票。
