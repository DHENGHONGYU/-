# 月度文档体系体检检查清单

> **定位**：每月运行一次的标准化检查流程，确保文档体系健康度持续达标。  
> **参照**：`docs/00-meta/文档体系体检报告-v9.md`（体检方法与数据 §5.1）。

---

## 一、基础体征（每月必查）

| # | 检查项 | 命令 | 健康阈值 | 异常处置 |
|---|--------|------|----------|----------|
| 1 | `.md` 文档总数 | `find docs -type f -name '*.md' | wc -l` | ≥ 400 | 低于阈值则检查是否误删 |
| 2 | `docs/` 子目录数 | `find docs -type d | wc -l` | 8±2（A–H）+ 主题包/归档 | 超发则检查自动产物/缓存 |
| 3 | 按 8 类体系可归类率 | 人工抽查 50 份 | ≥ 90% | 低于则扩展二级子类 |
| 4 | 孤儿文档（未覆盖） | `find docs -type f -name '*.md' | while read f; do ... done` | ≤ 5% | 归类或归档 |
| 5 | 应有文档缺口 | 对照体检报告 §缺陷 2 | 0 | 创建缺失文档 |
| 6 | 数据定义重复文件 | `find docs -name '*DATA_DEFINITION*' | wc -l` | 1（仅主字典） | 整合去重 |
| 7 | DEPRECATED 散落 | `find docs -path '*/0[1-6]-*' -name '*DEPRECATED*' | wc -l` | 0 | 迁入 07-archive/ |
| 8 | 空置目录 | `find docs -type d -empty` | 0 | 填充或删除 |

## 二、结构性缺陷（季度复查）

| # | 检查项 | 方法 | 健康阈值 | 异常处置 |
|---|--------|------|----------|----------|
| 9 | 目录名-内容错位 | `audit-path-match.ts`（P2-4） | 0 违规 | 迁移错位文档 |
| 10 | 自动产物隔离 | `ls docs/reports/*.html docs/reports/*.json 2>/dev/null | wc -l` | 0（应在 _generated/） | 移入 _generated/ |
| 11 | 草稿清理 | `find docs/drafts -type f -mtime +7 | wc -l` | 0 | 转正或删除 |
| 12 | 归档保留期 | `find docs/07-archive -type f -mtime +180 | wc -l` | 双人确认后删除 | 按 governance.md §4 |
