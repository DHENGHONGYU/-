## 二、治理目标与原则

### 2.1 短期目标（1-2周）

- ✅ 建立单一事实来源：《V9 数据宪法》作为权威文档
- ✅ 修复高优先级的数据不一致（3处严重问题）
- ✅ 建立数据变更审批流程

### 2.2 中期目标（1-2月）

- 统一所有重复定义，消除冗余
- 建立自动化的数据一致性检查
- 完善所有 Store 的 schema 文档
- 测试覆盖率达标（core ≥ 85%, services ≥ 70%）

### 2.3 长期目标（3-6月）

- 达到"已管理级"成熟度（80分以上）
- 建立数据血缘追踪能力
- 实现端到端的数据质量监控
- 建立数据治理 KPI 度量体系

### 2.4 治理原则

1. **单一事实来源**：每个数据实体有且仅有一个权威定义
2. **代码即文档**：TypeScript 类型是最高权威，文档次之
3. **变更可控**：所有数据结构变更必须经过评审和版本升级
4. **自动化优先**：尽可能用工具检查替代人工审计
5. **渐进式改进**：不追求一步到位，按优先级分批治理
