## 二、V6 界面设计事实（来自 SPA 逆向解析）

### 2.1 V6 技术栈与设计体系
- **形态**: React + Vite + Recharts 移动端 **PWA**（含 manifest / serviceWorker / modulepreload）
- **设计体系**: **shadcn/ui 标准 HSL 变量模型**（`--background/--primary/--card/--radius`），CSS 中 92 个变量
- **配色基调**: **深色优先** — 背景 `#0f172a`(slate-900)，强调色 `#10b981`(翡翠绿)，57 条 `.dark` 规则
- **界面结构**: 「九层漏斗 L0–L8 + v4 评分引擎」一体化：选股 / 分析 / 驾驶舱 / 自选 / 板块轮动 / 双引擎六维复盘 / 因子维度评分
- **数据可视化**: Recharts + Tailwind 全色系类别色板（红涨绿跌符合 A 股习惯：`#ef4444` 涨 / `#22c55e` 跌）

### 2.2 V6 vs V9 设计规格对照表

| 规格项 | V6 智能选股 | V9 投研复盘 | 判定 |
|---|---|---|---|
| 设计体系 | shadcn/ui 扁平令牌 | 6 层令牌 L1–L6 + 股票例外 L5 | 同源 |
| 主色 / 强调 | 翡翠绿 `#10b981`(HSL 160,84%,39%) | 青绿 `hsl(160,84%,31%)≈#0f9d76` | ≈同色相 |
| 默认主题 | **深色优先**(manifest 即暗底) | **主题感知**、默认跟随系统(桌面多亮色) | V6 更果断 |
| 设备取向 | 移动优先 PWA | 桌面驾驶舱为主(5 舱 + 40+ Widget) | 各有所长 |
| 图表色板 | Tailwind 默认全色系 | chartColors.ts 语义化 + 同全色系 | V9 更治理 |
| 统一隐喻 | 「九层漏斗」强心智模型 | Widget 网格，缺统一视觉锚点 | **V6 更强** |
| 治理 / 文档 | 无(Kimi 生成 Demo) | AGENTS.md 分层约束 + 零硬编码 + 文档体系 | **V9 碾压** |

## 三、成熟度评分卡（9 维度 · 5 分制）

### 3.1 雷达数据

| 维度 | V6 | V9 | 领先方 |
|---|---|---|---|
| 设计系统严谨度 | 3.0 | **5.0** | V9 |
| 视觉凝聚力 | **5.0** | 3.5 | V6 |
| 暗色 / 主题体验 | **4.0** | 3.0 | V6 |
| 信息密度 / 数据可视化 | 3.0 | **4.5** | V9 |
| 响应式 / 设备策略 | **4.5** | 2.5 | V6 |
| 品牌差异化 | 2.5 | **3.0** | V9 |
| 交互 / 状态设计 | **4.0** | 2.5 | V6 |
| 治理 / 可扩展 | 2.0 | **5.0** | V9 |
| 统一视觉隐喻 | **4.0** | 2.5 | V6 |
| **综合均分** | **3.56** | **3.56** | **持平** |

### 3.2 核心结论
- **均分完全相同(3.56)**，但优势领域截然不同：
  - V6 赢在「产品表面」：视觉凝聚力、暗色体验、响应式、交互状态、统一隐喻
  - V9 赢在「工程系统」：设计系统严谨度、信息密度、治理可扩展
- **这不是同一个坐标轴上的竞争** —— V6 是精致 Demo，V9 是工程系统

## 四、8 条核心洞察（来自成熟度评估）

| # | 洞察 | 影响 |
|---|---|---|
| I1 | **同源而异轨：系统是 V9，产品是 V6** | 不必照搬 V6，要补的是体验层而非重做设计系统 |
| I2 | **深色优先是交易类产品的默认正确** | V9 应为驾驶舱提供"暗色优先"或持久暗色档 |
| I3 | **范围收敛＝视觉凝聚** | V6 单屏天然一致；V9 的 40+ Widget 靠共享外壳 + 视觉 QA 闸门防漂移 |
| I4 | **缺一个签名视觉锚点** | V6 用九层漏斗；V9 是 Widget 网格缺记忆点 |
| I5 | **品牌色仍"通用"翡翠绿** | 缺辨识度，需沉淀差异化主色并保证 WCAG AA |
| I6 | **交互与状态设计是 V9 的空白带** | loading/empty/error/skeleton 未规范 |
| I7 | **令牌迁移债仍在** | `THEME_TOKENS.color` 仍暴露裸 Tailwind 色类 |
| I8 | **移动端是 V9 的盲区** | V6 mobile-native PWA；V9 桌面优先无响应式兜底 |

## 六、经典原则打分卡（V9 当前水位）

基于 10 条 Nielsen/Rams 经典设计原则：

| # | 原则 | 分类 | V9 水位 | 目标(80%) | 差距 |
|---|---|---|---|---|---|
| ① | 视觉层次 Visual Hierarchy | 美学 | **55% 中** | 80% | -25% |
| ② | 留白节奏 Negative Space | 美学 | **50% 中** | 80% | -30% |
| ③ | 色彩节制 60-30-10 Restraint | 美学 | **60% 中** | 80% | -20% |
| ④ | 排版秩序 Typographic Scale | 美学 | **58% 中** | 80% | -22% |
| ⑤ | 状态可见 System Visibility | 可用 | **35% 低** | 80% | **-45%** |
| ⑥ | 一致性 Consistency/Tokens | 可用 | **75% 高** ✅ | 80% | -5% |
| ⑦ | 渐进披露 Progressive Disclosure | 可用 | **30% 低** | 80% | **-50%** |
| ⑧ | 容错与安心 Error Prevention | 可用 | **45% 中** | 80% | -35% |
| ⑨ | 签名母题 Signature Metaphor | 创新 | **25% 低** | 80% | **-55%** |
| ⑩ | 有意义的美 Aesthetic+Honest | 创新 | **50% 中** | 80% | -30% |

**读图结论**:
- **唯一超目标线的项**: ⑥一致性(75%) — 这是 V9 的护城河（6 层令牌体系）
- **三项最低**: ⑤状态可见(35%)、⑦渐进披露(30%)、**⑨签名母题(25%)**
- 这三个最低项恰好对应实操方案的 **P1/P3/P2/P5** 阶段

## 七、V9 五大专属创新方向

> 创新不是堆特效，而是用经典原则解决 V9 独有场景（A股复盘、AI 辅助、个人研究）

| # | 创新点 | 差异化价值 | 对接阶段 |
|---|---|---|---|
| 1 | **复盘叙事流 Review Narrative** — 把复盘结论组织为时间轴（今日信号→持仓变化→策略反思→明日预案） | 区别于 V6 网格平铺和 WB 对话流，契合"复盘"语义 | P5 |
| 2 | **自适应密度 Adaptive Density** — 舒适/紧凑两档密度切换，由令牌统一驱动 | 金融用户两极分化，专业工具高级信号 | P0/P2 |
| 3 | **专注模式 Focus Dimming** — 暗色下 hover 某标的时其余面板自动压暗 | 把"暗色优先"从能看升级为会引导注意力 | P1 |
| 4 | **可解释配色 Explainable Color** — 悬停任意带色元素显示"为什么是这个颜色/是否示例" | 把 AI 免责声明变成产品亮点，合规即体验 | P3/P5 |
| 5 | **信号脉络 Signal Spectrum 母题** — 全局签名锚点，渐变光谱表达弱→强信号 | 对标 V6 九层漏斗，母题本身承载信息 | P2 |

## 八、验收闸门汇总

每个阶段的必须通过项（对齐 AGENTS.md 四步集成契约）：

| 阶段 | 闸门命令 | 量化标准 |
|---|---|---|
| P0 | `npx tsc --noEmit` + `npm run audit:docs` | 令牌 JSON 存在且被引用；主色 AA 校验 100% 通过 |
| P1 | `npm run audit:layers` + `npm run test -- --run` | 驾驶舱暗色覆盖率 100%；首屏无 FOUC；跨 Tab 同步正常 |
| P2 | `npm run audit:layers` + tsc | 核心 widget 100% 经 WidgetShell；锚点单测通过 |
| P3 | `npm run test -- --run` | 核心 8 widget 四态覆盖率 ≥90%；动效零魔法时长 |
| P4 | CI lint gate + token-scan | 裸色类 0 命中（白名单除外）；令牌扫描 0 违规 |
| P5 | tsc + test | 复盘成品卡可预览/导出；向导可跳过 |
| P6 | 手动移动验真 + skill 沉淀 | 核心 375px 断点不崩；巡检 skill 可用 |
