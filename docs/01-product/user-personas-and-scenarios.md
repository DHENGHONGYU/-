# V9 智能投研复盘系统 · 用户画像与使用场景

> **版本**: v1.0.0 ｜ **更新日期**: 2026-07-15 ｜ **文档类型**: 产品定位
> **研究方法**: 投资行为模型 + A 股散户画像 + 竞品用户分析 + V6 历史数据推演

## 1. 目标用户分层模型

基于 A 股个人投资者的**投资年限、资产规模、研究深度**三个维度，将目标用户划分为三层：

```
                    资深投资者
                        ↑  10%
                   ┌───────────┐
                   │  第三层    │ 长期价值投资者
                   │  (大师级)  │ 资产 500万+
                   └───────────┘
                        ↑  30%
                   ┌───────────┐
                   │  第二层    │ 进阶研究者
                   │  (精通级)  │ 资产 50-500万
                   └───────────┘
                        ↑  60%
                   ┌───────────┐
                   │  第一层    │ 初级投资者
                   │  (入门级)  │ 资产 10-50万
                   └───────────┘
```

**用户金字塔分布（预估）**：
- 第一层（入门）：60% — 新手与入门投资者，需要引导与框架
- 第二层（精通）：30% — 进阶研究者，需要效率与深度
- 第三层（大师）：10% — 资深投资者，需要定制与扩展

## 2. 核心用户画像

### 2.1 Persona 1：新手李明 — "我想系统地学会投资"

| 属性 | 描述 |
| :--- | :--- |
| **姓名** | 李明 |
| **年龄** | 28 岁 |
| **职业** | 互联网公司产品经理 |
| **所在城市** | 杭州 |
| **可投资资产** | 15-20 万 |
| **投资年限** | 1.5 年 |
| **投资风格** | 成长型 + 跟风型 |
| **年化收益** | -5% ~ +10% 波动大 |
| **使用工具** | 同花顺 APP、雪球、微信公众号 |

#### 核心痛点
1. **选股全靠感觉**：听朋友推荐、看公众号文章、追热点，缺乏系统的选股方法
2. **买卖时机混乱**：追涨杀跌，经常买在山顶、卖在谷底
3. **信息过载焦虑**：每天刷雪球/东财，信息太多不知道该信什么
4. **亏多赚少**：交了不少"学费"，但不知道问题出在哪
5. **想学习但无从下手**：买了很多投资书，理论懂了但不会实战

#### V9 核心价值
- **V6 九维评分**：提供系统化选股框架，从"凭感觉"到"有依据"
- **五舱工作流**：引导建立规范的研究习惯，避免情绪化决策
- **热门板块 + 候选池**：降低入门门槛，快速找到研究对象
- **策略回测（基础）**：用历史数据验证简单策略，建立数据驱动思维

#### 使用场景
- 周末花 2 小时，用 V9 筛选下周关注标的
- 盘后简单复盘当天操作，记录笔记
- 模拟不同选股条件，学习基本面分析

#### 关键转化路径
```
新手注册 → 热门板块引导 → 加入候选池 → 一键评分 → 看懂评分维度 → 
建立第一个自定义筛选条件 → 每周选股习惯养成 → 进阶用户
```

### 2.2 Persona 2：进阶张薇 — "我有自己的方法，但想更高效"

| 属性 | 描述 |
| :--- | :--- |
| **姓名** | 张薇 |
| **年龄** | 36 岁 |
| **职业** | 三甲医院主治医师 |
| **所在城市** | 上海 |
| **可投资资产** | 200-300 万 |
| **投资年限** | 6 年 |
| **投资风格** | 价值投资 + 成长股结合 |
| **年化收益** | +8% ~ +15% 较稳定 |
| **使用工具** | 东方财富 Choice（试用版）、Excel、自己的笔记系统 |

#### 核心痛点
1. **研究效率低**：每天晚上花 2-3 小时研究，但感觉进度慢
2. **数据分散**：财务数据在 Choice，行情在东财，笔记在 Notion，切换成本高
3. **策略难验证**：想出来的选股逻辑不知道历史上是否有效
4. **缺乏复盘机制**：买卖凭经验，犯过的错有时候还会再犯
5. **认知难沉淀**：研究了很多公司，但知识散落在各处，难系统回顾

#### V9 核心价值
- **多因子筛选引擎**：自定义选股逻辑，快速筛选符合条件的标的
- **策略回测系统**：验证策略有效性，用数据说话而非凭感觉
- **交易复盘笔记**：结构化复盘，沉淀认知，避免重复犯错
- **行业评分 + 板块轮动**：把握宏观节奏，不只盯个股
- **本地知识库**：统一管理研究资料，打造个人投研中台

#### 使用场景
- 每日盘后 30 分钟：检查持仓评分变化、记录当日交易笔记
- 每周六 3 小时：系统筛选新标的、更新股票池、研究重点公司
- 每月底：月度复盘，回顾策略表现、调整仓位配置
- 不定期：灵感来了就回测一个新思路

#### 关键转化路径
```
从 V6 升级 / 发现 V9 → 导入历史数据 → 体验 V9 新功能（行业评分/策略回测）→
发现效率提升 → 建立每日/每周使用习惯 → 成为深度用户 → 推荐给朋友
```

### 2.3 Persona 3：资深老王 — "工具要能支撑我的体系"

| 属性 | 描述 |
| :--- | :--- |
| **姓名** | 王建国 |
| **年龄** | 48 岁 |
| **职业** | 民营企业创始人（已半退休） |
| **所在城市** | 深圳 |
| **可投资资产** | 800-1200 万 |
| **投资年限** | 15 年 |
| **投资风格** | 深度价值 + 长期持有 |
| **年化收益** | +12% ~ +20% 穿越牛熊 |
| **使用工具** | Wind 金融终端（万得）、彭博（偶尔）、自己的投资数据库 |

#### 核心痛点
1. **Wind 太重太贵**：每年几万块，但很多功能用不上，性价比低
2. **数据管理成本高**：自己的研究数据、笔记、估值模型分散在多个工具里
3. **定制需求难满足**：通用工具无法完全贴合自己的投资方法论
4. **隐私与主权**：核心持仓和研究思路放在第三方平台不放心
5. **认知沉淀难**：十五年投资经验，想系统化沉淀但缺合适工具

#### V9 核心价值
- **纯前端 + 本地数据主权**：所有数据存本地，隐私安全，零服务器依赖
- **高度可定制**：Widget 插件化、自定义评分、自定义策略，贴合个人体系
- **轻量高效**：专注研究核心功能，没有行情推送、社交等噪音
- **知识库 + 评分文档**：结构化管理十五年研究积累
- **AI 深度分析**：基于个人历史数据的 AI 助手，发现盲点和模式
- **MCP 生态扩展**：接入自有数据源、分析工具，打造个人投研平台

#### 使用场景
- 每日早晨 1 小时：浏览持仓变化、阅读重要资讯、调整观察清单
- 每周深度研究 1-2 家公司：用评分系统 + 知识库做深度分析
- 每月策略回顾：检查组合表现、评估行业配置、做再平衡决策
- 不定期：开发新的分析 Widget、接入新的数据源、优化个人投研体系

#### 关键转化路径
```
发现 V9（技术圈/投资圈推荐）→ 体验数据主权 + 可定制性 → 
导入历史数据 → 开发个人专属 Widget → 建立个人投研工作流 → 
成为生态贡献者（分享 Widget/策略）
```

## 3. 典型使用场景

### 3.1 场景一：周末选股研究（全用户层）

**用户**：李明（新手）/ 张薇（进阶）/ 老王（资深）
**频率**：每周六/日，1-4 小时
**核心路径**：

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│  输入舱   │ → │  分析舱   │ → │  输出舱   │ → │  交易舱   │
│ 确定范围  │   │ 多维评分  │   │ 研究报告  │   │ 加入观察  │
│ 热门板块  │   │ 筛选排序  │   │ 导出备份  │   │ 信号跟踪  │
└──────────┘   └──────────┘   └──────────┘   └──────────┘
```

**步骤分解**：

| 步骤 | 操作 | 李明（新手） | 张薇（进阶） | 老王（资深） |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 打开 V9，进入输入舱 | 浏览热门板块，选 2-3 个感兴趣的 | 从自选板块开始，补充行业轮动信号 | 直接从自定义股票池开始 |
| 2 | 一键加入候选池 | 选 10-15 只加入观察 | 选 20-30 只做初筛 | 从 50+ 只股票池精细筛选 |
| 3 | 进入分析舱评分 | 用默认 V6 九维评分 | 用自定义权重评分 + 行业评分 | 用个人定制评分模型 + AI 深度分析 |
| 4 | 筛选排序 | 按总分排序，看前 5 名 | 按多个维度交叉筛选 | 按自定义因子排序 + 人工复核 |
| 5 | 深度研究 Top3 | 看评分详情，了解各维度得分 | 看财务明细 + 行业对比 + 资讯 | 深度分析 + 知识库关联 + 估值模型 |
| 6 | 导出/记录 | 导出 JSON 留档 | 写研究笔记 + 导出报告 | 生成完整研究文档 + 加入知识库 |
| 7 | 加入交易观察 | 简单加入观察池 | 设置价格提醒 + 风控参数 | 建立策略跟踪 + 自动信号 |

### 3.2 场景二：盘后交易复盘（进阶/资深）

**用户**：张薇（进阶）/ 老王（资深）
**频率**：每个交易日晚，20-60 分钟
**核心路径**：

```
┌──────────┐   ┌──────────┐   ┌──────────┐
│  交易舱   │ → │  分析舱   │ → │  总控舱   │
│ 交易记录  │   │ 评分对比  │   │ 复盘总结  │
│ 持仓检查  │   │ 信号验证  │   │ 认知沉淀  │
└──────────┘   └──────────┘   └──────────┘
```

**关键动作**：
1. 检查当日交易记录（买入/卖出/调仓）
2. 对照评分系统，验证决策依据是否充分
3. 记录交易笔记：买入理由、卖出理由、情绪状态
4. 检查持仓股票评分变化，识别风险信号
5. 更新观察池，标记重点关注标的
6. （每周）统计本周胜率、盈亏比、最大回撤

---

### 3.3 场景三：策略回测验证（进阶/资深）

**用户**：张薇（进阶）/ 老王（资深）
**频率**：每月 2-4 次，每次 30-90 分钟
**核心路径**：

```
┌──────────┐   ┌──────────┐   ┌──────────┐
│  输入舱   │ → │  分析舱   │ → │  输出舱   │
│ 股票池    │   │ 策略配置  │   │ 回测报告  │
│ 历史数据  │   │ 回测执行  │   │ 结果对比  │
└──────────┘   └──────────┘   └──────────┘
```

**关键动作**：
1. 定义选股策略（如：低 PE + 高 ROE + 行业龙头）
2. 选择回测时间段（如：近 3 年 / 近 5 年 / 上一轮牛熊）
3. 设置交易规则（持仓数、调仓频率、止损止盈）
4. 运行回测，查看收益曲线、最大回撤、胜率
5. 调整参数，对比不同版本表现
6. 导出回测报告，归档到知识库

### 3.4 场景四：深度个股研究（资深）

**用户**：老王（资深）/ 张薇（进阶）
**频率**：每周 1-2 只，每次 2-4 小时
**核心路径**：

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│  输入舱   │ → │  分析舱   │ → │  输出舱   │ → │  知识库   │
│ 标的选定  │   │ 11 维评分 │   │ 研究报告  │   │ 知识沉淀  │
│ 资料收集  │   │ AI 分析   │   │ 估值模型  │   │ 持续追踪  │
└──────────┘   └──────────┘   └──────────┘   └──────────┘
```

**关键动作**：
1. 选定研究标的，收集相关资讯、财报、行业数据
2. 运行 V6 评分 + 智能评分，获取多维度评估
3. 深入分析财务报表、业务模式、竞争格局
4. 建立估值模型，计算合理价格区间
5. 生成完整研究报告，包含投资逻辑、风险点、跟踪指标
6. 归档到知识库，建立长期跟踪档案

### 3.5 场景五：V6 用户数据迁移（存量用户）

**用户**：V6 Pro 老用户
**频率**：一次性，约 30 分钟
**核心路径**：

```
┌──────────┐   ┌──────────┐   ┌──────────┐
│ 数据导出  │ → │  总控舱   │ → │ 验证确认  │
│ V6 导出   │   │ 迁移工具  │   │ 数据比对  │
│ 备份文件  │   │ 一键导入  │   │ 平滑过渡  │
└──────────┘   └──────────┘   └──────────┘
```

**关键动作**：
1. 从 V6 Pro 导出完整数据（股票池、评分历史、交易记录、笔记）
2. 在 V9 总控舱打开迁移工具
3. 上传 V6 导出文件，预览迁移内容
4. 执行迁移，等待数据转换完成
5. 验证迁移后数据完整性（抽样比对）
6. 确认迁移成功，开始使用 V9

## 6. 非用户角色（Stakeholders）

### 6.1 开发者/贡献者
- **需求**：完善的开发文档、清晰的架构设计、可扩展的插件机制
- **价值**：参与一个有实际用户的开源项目、学习前沿技术栈、个人品牌

### 6.2 数据服务商
- **需求**：标准化的数据接入接口、用户数据脱敏、合规保障
- **价值**：触达高质量个人投资者、新的分发渠道

### 6.3 投资博主/教育者
- **需求**：策略分享、教学案例、学员管理
- **价值**：教学工具、内容载体、社区运营
