# 无障碍与国际化指南（A11y & i18n）

> **定位**：定义 V9 的无障碍（A11y）与国际化（i18n）基线，补 H 类指南缺口（P2-3）。
> **状态**：? P2 新增（基线版）

---

## 1. 无障碍（Accessibility）

### 1.1 对比度
- 文本与背景对比度 ≥ WCAG AA（正文 4.5:1，大字 3:1）。宋韵 `stone` 体系天然满足；强调色 `emerald-500` 仅用于非纯文本语义。
- 涨跌固定色（红 `red-500` / 绿 `green-500`）在图表中须配文字/形状双重编码，避免色盲歧义。

### 1.2 键盘与焦点
- 所有交互元素可 Tab 聚焦；焦点环走 `THEME_TOKENS.focusVisible`。
- 弹窗/模态须可 Esc 关闭、焦点陷阱（focus trap）。

### 1.3 语义与 ARIA
- 用原生语义标签（button/nav/main）；自定义组件补 `role` / `aria-*`。
- 图表（Recharts / lightweight-charts）提供 `aria-label` 与数据表回退。

### 1.4 动效
- 尊重 `prefers-reduced-motion`：减少非必要动画。

## 2. 国际化（i18n）

### 2.1 现状
- 当前界面以**简体中文**为唯一语言（面向中国个人投资者）。
- 地域约定：**股票涨→红、跌→绿**（中国习惯，与欧美相反），全局固定，不随 locale 翻转。

### 2.2 策略（若未来多语）
- 文案抽离至 i18n 资源（key-based），禁止硬编码于组件。
- 数值/货币：默认 ￥（CNY）；日期/时区走用户区域。
- 涨跌色仍按中国市场固定（红涨绿跌），不因语言切换改变。

### 2.3 验收
- ? 关键路径键盘可达；焦点可见。
- ? 涨跌色双重编码（色+形/文）。
- ? 无散落硬编码文案（多语时由 i18n 层统一）。
