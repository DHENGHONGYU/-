### 规则 #11: 正则动态构?
| 属?| ?|
|------|-----|
| **严重级别** | ERROR（JS/TS? WARN（Python）|
| **首次发现** | V9 2026-07-03 |
| **检查器** | `check_regex_dynamic_construction` |

**问题描述**：JavaScript 字面量正?`/v_${var}=/` 中的 `${var}` 不会插值，被当作字面字符串，导致正则匹配静默失败?
**根因**：JS 字面量正?`/.../` 不支持模板字符串插值，必须?`new RegExp()` 构造?
**铁律**：动态正则必须用 `new RegExp()` 构造，禁止在字面量正则中使?`${var}`?
**违规示例（JS/TS?*?
```javascript

```

**修复示例（JS/TS?*?

**Python 注意事项**?

### 规则 #13: TTL+LRU 缓存
