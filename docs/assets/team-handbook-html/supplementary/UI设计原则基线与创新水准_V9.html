UI 设计原则基线与创新水准

你不必是设计专家。我把业界公认的「经典设计美学原则」立为一把标尺：先定义什么叫"设计水准"，再给 V9 逐条打分、定位缺口，并标出 V9 能超越参考站、做出自身创新的方向。这份文档就是你的评审尺与创意清单。

1经典设计原则基线（你的评审尺）

下面 10 条来自设计界公认的权威框架，按"美学 / 可用 / 一致 / 创新"四类组织。每条都给出：大白话解释 + V9 当前水准 + 对应缺口动作。评分：高 已达标 / 中 部分 / 低 缺失。

🎨 美学层（好看且有秩序）

① 视觉层次 Visual Hierarchy

用大小、粗细、留白、颜色告诉用户"先看哪、再看哪"。好界面像报纸头版，重点一眼可见。

V9 缺口：信息密度高但层级靠"堆"，关键数字与次要标签视觉权重拉不开。
中

② 留白与节奏 Negative Space

空白不是浪费，是呼吸感。恰当的间距让界面"贵气"且易读（WorkBuddy 的克制留白即此理）。

V9 缺口：卡片内边距/段距偏紧，密集表格缺乏分组留白。
中

③ 色彩节制 60-30-10 / Restraint

主色占 60%、辅色 30%、强调色仅 10%。强调色越稀有，点击欲越强（Rams：尽可能少设计）。

V9 缺口：语义色（涨红跌绿+评分+信号）多，强调色被稀释；需"单一克制强调色"公约。
中

④ 排版秩序 Typographic Scale

字号/字重成比例阶梯（如 1.25 倍率），而非随手定。数字用等宽/表格数字对齐，专业感立现。

V9 缺口：金融数字未强制 tabular-nums，跨行对不齐；字号阶梯未完全令牌化。
中

🧭 可用层（好用且不费脑）

⑤ 系统状态可见 Nielsen #1

用户随时知道"系统在干嘛、数据新不新"。加载中、刷新时间、过期提醒都要明示。

V9 缺口：板块轮动等合成数据缺"示例/时效"标识（已知约定），四态（加载/空/错/骨架）未规范。
低

⑥ 一致性 Nielsen #4 / Tokens

相同操作处处相同。靠设计令牌而非散落常量保证——V9 的 6 层令牌体系正是为此。

V9 缺口：令牌迁移债（裸色类）仍在，跨 widget 视觉漂移风险。
高

⑦ 渐进披露 Progressive Disclosure

新手看精简，专家挖深层。不一次倒出所有，按需要展开（WorkBuddy 模式切换即范例）。

V9 缺口：五舱全屏平铺，新手易迷失；缺"向导式复盘"。
低

⑧ 容错与安心 Nielsen #5/#9

防呆 + 出错可恢复。金融场景尤其要"这是 AI 参考、非建议"的安心标识。

V9 缺口：错误态/空态未统一；免责标注散落，未成体系。
中

💡 创新层（超越而非照搬）

⑨ 签名母题 Signature Metaphor

一个全局一致的视觉母题作记忆点（V6 的"九层漏斗"即此）。比配色更能让人记住你。

V9 缺口：缺专属锚点；这是"创新"而非"修补"的主战场。
低

⑩ 有意义的美 Rams: Aesthetic + Honest

美不是装饰，要诚实表达数据。动画/配色都在"帮用户理解"，而非炫技。

V9 机会：把"复盘叙事""可解释配色"做成有思想的创新，而非堆特效。
中

3V9 专属创新点（超越 V6 / WorkBuddy）

创新不是堆特效，而是用经典原则解决 V9 独有场景（A股复盘、AI 辅助、个人研究）。下面 5 个点是"V9 味"的创新，避免与参考站同质化。

🧭

创新 1 · 复盘叙事流（Review Narrative）

差异化 · 高

V6 是"网格平铺 dashboard"，WorkBuddy 是"对话流"。V9 可做第三种形态：把复盘结论组织成一条可滚动的"叙事时间轴"——从"今日信号 → 持仓变化 → 策略反思 → 明日预案"，像读一份有逻辑的投研笔记，而非看一堆卡片。

为何创新：契合"复盘"语义（叙事性），比网格更有记忆点，且天然适配渐进披露（新手看主线，专家展开支线）。

P5叙事时间轴组件区别于 V6 网格
🎚️

创新 2 · 自适应密度（Adaptive Density）

体验 · 中

遵循 Rams"为不同的人设计"。提供舒适 / 紧凑两档密度切换：新手用舒适档（大留白、少数据），老手用紧凑档（一屏更多 Alpha）。密度由令牌（间距/字号）统一驱动，不破坏一致性。

为何创新：金融用户两极分化明显，单一密度难兼顾；这是"专业工具"的高级信号。

P0/P2密度令牌用户偏好持久化
🫧

创新 3 · 专注模式（Focus Dimming）

暗色 · 中

暗色驾驶舱下，hover/选中某只标的或某条信号时，其余面板自动"压暗"，让注意力聚焦。这是暗色主题独有的"光影叙事"，亮色难以实现。

为何创新：把 P1 的"暗色优先"从"能看"升级为"会引导注意力"，是暗色价值的真正兑现。

P1暗色压暗动效注意力引导
🔍

创新 4 · 可解释配色（Explainable Color）

信任 · 高

悬停任意带色元素（红/绿/评分条），浮层说明"为什么是这个颜色 / 数据来自哪 / 是否示例"。把"AI 仅供参考"的合规要求，变成一种透明、可信任的交互体验。

为何创新：金融场景"信任"是核心；把免责变成产品亮点，而非角落小字——这是 V9（个人研究工具）独有的合规创新。

P3/P5颜色悬停释义合规即体验
🪢

创新 5 · 信号脉络（Signal Spectrum 母题）

签名 · 高

作为 V9 的全局签名母题（对标 V6 九层漏斗）：一条贯穿所有 widget 的"信号强度谱"——用统一的渐变光谱表达"弱→强"信号，既是视觉锚点，又自带数据含义。

为何创新：母题本身承载信息（不只是装饰），符合原则⑩"有意义的美"；且光谱隐喻比漏斗更契合"市场情绪连续体"。

P2SignalSpectrum 组件全局锚点

4非专家也能用的设计评审清单

你不需要懂设计，按这条清单逐条打勾，就能守住"设计水准"。每条都对应上面的经典原则。

  • 层次：打开任意页面，3 秒内能否说出"最重要的一个数字/动作"在哪？（原则①）
  • 留白：卡片之间、段落之间是否有"呼吸感"，不挤成一团？（原则②）
  • 色彩：全站是否只有一个最显眼的"主行动色"，其余都是中性/语义色？（原则③）
  • 数字：表格里的金额/百分比是否上下对齐、等宽，不歪歪扭扭？（原则④）
  • 状态：加载时、没数据时、出错时，界面是否都有明确反馈，不空白卡死？（原则⑤）
  • 一致：相同按钮/卡片在不同页面是否长得一样？（原则⑥）
  • 渐进：新手进来是否有引导，老手能否一键跳过看深层？（原则⑦）
  • 安心：AI 生成内容是否清晰标注"仅供参考/非建议"？（原则⑧）
  • 母题：能否用一句话说清 V9 的"视觉招牌"是什么？（原则⑨）
  • 意义：每一个动画/配色是否都在"帮理解"，而非单纯好看？（原则⑩）
使用法：每次发布前过一遍，任一项打不了勾 → 对应阶段（P0–P6）回炉。这把"我觉得不好看"变成"第 X 条原则未达标"的客观判断。

6小白术语表

评审时遇到听不懂的词，查这里。

设计令牌 (Token)把颜色/间距/圆角等存成"变量"，全站统一引用，改一处全局变。
视觉层次用大小粗细引导视线先看哪，像报纸头版。
留白 (Negative Space)元素之间的空，不是浪费，是呼吸感与高级感来源。
60-30-10配色比例法则：主色60%、辅色30%、强调色仅10%。
渐进披露先给简单，需要时再展开复杂，避免一次倒给用户。
签名母题一个贯穿全站的视觉符号/隐喻，让人记住你（如 V6 漏斗）。
暗色优先交易类工具默认深色底，护眼且数据更突出。
WCAG AA无障碍对比度国际标准，文字与背景亮度差≥4.5:1 才算合格。
tabular-nums数字等宽对齐，表格金额上下对齐不乱。
FOUC页面先白闪再变暗的瑕疵，需提前设主题避免。
