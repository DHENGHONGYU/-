5核心洞察

Insight 01

同源而异轨：系统是 V9，产品是 V6

二者都生于 shadcn/ui，主色同处色相 160 附近。V9 把"设计系统"做成了工程资产（6 层令牌、治理），V6 把"设计"做成了用户可感知的成品。成熟度不是同一个坐标轴。

Insight 02

深色优先是交易类产品的默认正确

V6 直接 dark-first（manifest 即暗底）；V9 默认跟随系统、桌面多亮色。投研/交易场景长时盯盘，暗色降低眩光、突出数据——V9 应为驾驶舱提供"暗色优先"或持久暗色档。

Insight 03

范围收敛＝视觉凝聚

V6 单屏闭环天然一致；V9 的 40+ Widget 即便有 WidgetShell/Card，仍易各自漂移。凝聚不靠"少做"，靠"共享外壳 + 视觉 QA 闸门"。

Insight 04

缺一个签名视觉锚点

V6 用「九层漏斗」建立强心智模型与签名图形；V9 是 Widget 网格，信息强但缺记忆点。需为驾驶舱注入统一隐喻（评分谱/漏斗/信号流）。

Insight 05

品牌色仍"通用"

双方主色都是翡翠/青绿（emerald 系），专业但缺乏辨识度。可沉淀一个 finance-appropriate 的差异化主色（深青/靛/紫），并保证对比度可达 WCAG AA。

Insight 06

交互与状态设计是 V9 的空白带

V9 的 AGENTS.md 强制日志与清理，却未规范 loading / empty / error / skeleton / 微动效。精致感恰来自这些"看不见"的状态。

Insight 07

令牌迁移债仍在

THEME_TOKENS.color 仍暴露 text-blue-500 等裸类（设计文件已标注"历史遗留"）。新代码应只走 SEMANTIC_COLOR_ROLES，否则主题切换会漏色。

Insight 08

移动端是 V9 的盲区

V6 是 mobile-native PWA；V9 桌面优先，关键舱室无响应式兜底。投研者常在手机速览——至少核心驾驶舱/自选需移动适配。

6整改事项清单（按优先级）

P0

驾驶舱暗色优先 + 持久暗色档

为投研/交易场景默认暗色，提供"跟随系统 / 浅 / 深"三态，深为默认。复用现有 .dark 变量。

中影响：高
P0

统一视觉锚点（评分谱 / 漏斗隐喻）

在驾驶舱植入一个签名图形（如九层评分谱或信号流），建立记忆点，弥补 Widget 网格的松散感。

中影响：高
P1

令牌迁移债清零

逐步替换 THEME_TOKENS.color 裸类为 SEMANTIC_COLOR_ROLES；新增 lint 规则禁止 text-blue-500 等硬编码色类。

中影响：中
P1

交互与状态设计标准

补充 loading / empty / error / skeleton / hover·focus / 微动效规范，纳入 AGENTS.md 与组件审查清单。

中影响：高
P1

视觉 QA 闸门（防规模漂移）

CI 增加"设计令牌lint + 关键页截图 diff"，确保 40+ Widget 跨版本视觉一致。

高影响：高
P2

差异化品牌主色

在青绿基线上微调出专属色（如偏靛的深青），校验对比度 AA，统一应用到 accent / 选中 / 强调。

低影响：中
P2

核心舱室移动适配

驾驶舱 / 自选股至少做 responsive 兜底（栅格降列、触控目标≥44px），拥抱移动速览场景。

中影响：中
P3

沉淀"设计对照"常态化机制

把本次 SPA 逆向比对法固化为竞品/参考站巡检流程，定期校准配色与交互趋势。

低影响：低

7网页设计与优化能力升级清单

  • 建立设计基线：以现有 6 层令牌为唯一真源，所有 UI 经令牌取色，禁用裸 HEX/色类。
  • 暗色优先决策：数据密集型产品默认暗色，降低眩光、突出信息。
  • 签名隐喻：每个核心页面有一个可记忆的视觉锚点（谱/漏斗/流）。
  • 共享外壳：WidgetShell + Card 强制包裹，统一圆角/间距/标题/操作区。
  • 状态全谱：loading / empty / error / skeleton / 边界态均有设计，不裸奔。
  • 微动效克制：过渡 150–250ms，hover/focus 反馈明确，不炫技。
  • 字体阶梯：落实 TYPOGRAPHY_SCALE，数字用等宽栈右对齐，建立清晰层级。
  • 对比度达标：主色与背景对比度≥ WCAG AA（4.5:1 文本 / 3:1 大字号）。
  • 间距栅格化：用 LAYOUT_TOKENS 统一容器内边距与区块间距。
  • 图表语义化：类别色走 chartColors.ts，涨跌走股票例外令牌，禁止内联。
  • 响应式兜底：关键视图在窄屏可降级阅读，触控目标≥44px。
  • 视觉回归：CI 截图 diff + 令牌 lint，规模扩张不丢一致性。
