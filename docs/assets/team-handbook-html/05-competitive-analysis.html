05 · 竞品对比分析（Competitive Analysis）

本文回答"我们凭什么差异化"。基线参考：docs/01-product/competitive-analysis.md（分析 5 大类 12 款工具）。 ⚠️ 说明：竞品的功能/架构描述基于公开认知与一般行业常识；性能维度多为定性推断，非基准测试。涉及具体数字请以各产品官方披露为准。本分析用于团队内部战略对齐，不构成第三方评价结论。

4. V9 的四大差异化支柱

  1. 数据主权（最根本） 数据 100% 存本地、零上传。竞品几乎全部云端采集，用户数据归平台。隐私觉醒趋势下这是越来越强的卖点。

  2. 方法论驱动而非信息驱动 五舱工作流 = 投资方法论软件化，把"输入→分析→交易→输出→总控"固化为连续研究流，配合"不切屏原则"保持心流。竞品多偏"数据查询/资讯推送"，V9 偏"研究方法论与复盘体系"。

  3. AI 增强但不替代（白盒可解释） 双轨评分：V6 规则引擎 100% 可解释 + AI 评分透明可追溯，交叉验证。区别于"AI 替你做决策"的黑箱投顾——用户始终掌握最终决策权。

  4. 可扩展平台（工具→平台→生态） 驾驶舱 Widget 市场 + 15 个 MCP Server 生态 + Web Worker 计算池。竞品多为固定功能集，V9 预留"接入无限第三方工具/数据"的协议化通道。

附加护城河：认知复利——评分历史 + 复盘笔记 + 知识库，把"信息消费"变成"认知生产"，迁移成本即壁垒。

5. 能力差距与风险（诚实评估）

维度 V9 现状 差距/风险 应对
实时性 盘后/历史为主，无盘中推送 不满足盯盘族 明确"研究复盘"定位，不硬刚实时行情
数据广度 依赖第三方行情源（腾讯/新浪兜底） 广度受限、有降级风险 强化 MCP 接入、明确数据源 SLA
算力规模 单浏览器 Worker 池（≤4） 无法跑大规模回测/训练 架构预留 Gateway，V10 评估服务端
生态成熟度 15 MCP Server，早期 远不及 Wind/同花顺生态 聚焦"个人研究"垂直场景，做深不做广
合规 纯前端规避集中数据合规 但 AI 输出须持续标注"非投资建议" 固化 disclaimer 组件，门禁校验
协作 单用户本地 无多人协作/云同步 暂不在范围；V10 评估可选同步

6. 战略建议

  1. 守住蓝海定位：不与行情交易工具拼实时，不与机构终端拼数据广度，死守"个人研究操作系统 + 数据主权 + 认知复利"。
  2. 补齐关键短板：在"研究"闭环内做深——更丰富的复盘模板、更强的信号可解释性、更顺滑的 MCP 接入体验。
  3. 开放生态：把 Widget 市场与 MCP Server 做成"可贡献"机制，让早期用户成为生态共建者（护城河正向循环）。
  4. 架构演进节奏：当前纯前端是有意选择（合规/成本/隐私）；只有当规模 > 1 万且需集中数据时，才在 V10 评估引入 Gateway 服务端，避免过早复杂化。
