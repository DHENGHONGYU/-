## 🟡 P1 问题（强烈建议）

- [ ] 命名规范（kebab-case/ PascalCase/ camelCase）
- [ ] 函数长度 < 50 行
- [ ] 文件长度 < 300 行
- [ ] 圈复杂度 < 10
- [ ] 无重复代码
- [ ] React 性能优化（memo/useMemo/useCallback）
- [ ] 懒加载（React.lazy）
- [ ] 防抖节流（搜索/滚动）
- [ ] 注释清晰（JSDoc）
- [ ] 日志规范（[模块名] 操作名）

---

## 🟢 P2 问题（可选改进）

- [ ] 代码风格一致
- [ ] 简化代码（数组方法替代循环）
- [ ] 类型推导（减少冗余类型注解）
- [ ] React 最佳实践（避免内联对象/函数）
- [ ] Zustand 最佳实践（shallow 比较）
- [ ] Tailwind 最佳实践（提取重复类名）

## 🚀 本地验证命令（提交前必须全部通过）

```powershell
# 完整验证
npm run lint              # ESLint 检查
npx tsc --noEmit         # TypeScript 类型检查
npm test -- --run         # 单元测试
npm run build             # 生产构建

# 架构审计
npm run audit:layers      # 分层调用
npm run audit:hardcode    # 硬编码
npm run audit:deadcode    # 死代码
npm run audit:docs        # 文档同步

# 快速自检（推荐）
npm run pre-review        # 一键执行所有检查
```
