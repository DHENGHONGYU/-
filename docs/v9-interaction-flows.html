V9 智能投研复盘系统

各功能板块人机交互时序与操作流程梳理

1. 数据采集（输入舱）

入口：输入舱 → 七维采集配置 核心：SevenDimConfigPage / CollectTaskPage 状态：collectionRuntimeStore / sevenDimConfigStore
  1. 用户进入「输入舱」→ 点击「七维采集配置」→系统展示策略模板、8 个采集维度开关与全局参数
  2. 用户选择策略模板（价值 / 成长 / 防御 / 周期 / 全维度）→系统自动勾选推荐维度并预置频率与数据源
  3. 用户开启/关闭维度，调整频率、数据源优先级、字段列表→系统实时估算月调用量与额度使用率
  4. 用户设置标的数量、历史天数→系统更新预估调用次数与限流风险提示
  5. 用户点击「保存配置」→系统将维度配置持久化到 Store / IDB
  6. 用户点击「开始采集」→系统进入采集中状态，按 MVP 模拟进度更新（0% → 100%）；真实批量采集、数据源优先级链与降级逻辑待后续接入 collectionPipeline / orchestrator
  7. 用户切换至「采集任务监控」页→系统展示 collectionRuntimeStore 中的任务列表、维度健康度、实时日志、时间线、泳道图与链路回放
  8. 用户点击某任务「详情」→系统聚焦该任务的 trace 时间线与泳道视图
关键事件：collect:triggered → source:start/success/fail → fallback → transform → write:success/fail → complete。
复核注：SevenDimConfigPage.runCollection() 当前为 MVP 模拟进度，尚未调用真实采集服务；真实任务状态由 collectionRuntimeStore 独立维护。

2. 个股分析（分析舱）

入口：分析舱 → 个股分析 核心：StockAnalysisPage 状态：stockAnalysisStore
  1. 用户进入「个股分析」页，URL 携带股票代码 symbol→系统加载股票基本信息、最新价、PE/PB 等概览
  2. 系统自动拉取 K 线历史数据→渲染蜡烛图，展示最新开/高/低/收与成交量
  3. 用户点击「运行 V6 评分」→系统调用评分服务，展示综合评分与九维因子得分
  4. 系统展示评分历史面板→用户可查看历史评分变化趋势与数据血缘（real / mock）
数据血缘提示：若数据来源为 Mock，会展示「Mock 数据」destructive 徽章；真实来源展示数据源标签

3. 多因子筛选 / 股票池（分析舱）

入口：分析舱 → 多因子筛选 核心：MultiFactorFilterPage / MultiFactorFilterPanel 状态：multiFactorScreeningStore
  1. 用户进入「多因子筛选」页→系统展示默认条件组与因子库
  2. 用户点击「添加条件组」→系统新增一个条件组，并设置组内逻辑（AND / OR）
  3. 用户在条件组内点击「添加条件」→系统新增一行：因子选择、操作符、数值输入（between 时含上下限）
  4. 用户切换因子、操作符，输入阈值→系统实时校验并根据因子元数据推荐默认值
  5. 用户输入模板名称并点击「保存模板」→系统将当前条件组持久化为可复用模板
  6. 用户从下拉框选择已保存模板并点击「加载」→系统还原模板条件
  7. 用户点击「运行筛选」→系统执行筛选逻辑，返回符合条件的股票列表
  8. 用户点击「导出结果 CSV」→系统将结果导出为 CSV 文件
筛选结果写入 multiFactorScreeningStore.results，当前仅支持「导出结果 CSV」，页面内暂缺结果表格/列表展示组件（ScreeningResultList 待补充）

4. 策略回测（分析舱）

入口：分析舱 → 策略回测 核心：BacktestPage 状态：backtestStore
  1. 用户进入「策略回测」页→系统展示回测配置面板与默认参数
  2. 用户选择策略类型（热门板块 / 价值洼地 / 复合策略）→系统更新策略配置
  3. 用户设置开始日期、结束日期、初始资金→系统校验日期区间与资金合理性
  4. 用户点击「开始回测」→系统模拟历史交易，计算净值曲线、收益指标、交易记录
  5. 系统展示回测结果→用户可查看总收益率、年化收益、最大回撤、夏普比率、胜率、交易次数等绩效指标
  6. 用户切换「绩效指标 / 交易记录 / 持仓快照」Tab→系统展示对应视图
  7. 用户点击「导出报告」→系统导出 PDF 格式回测报告
  8. 用户点击「清除结果」→系统清空当前回测结果，回到初始状态
默认手续费率 0.03%、滑点 0.1%、单股最大仓位 20%，显示在配置面板下方

5. 交易流程（交易舱）

入口：交易舱 → 交易流程 核心：TradingFlowPage 状态：tradingStore
  1. 用户进入「交易流程」页→系统加载自选股、交易信号、订单、持仓与风险指标
  2. 用户在「交易信号」面板查看 buy/sell 信号→系统展示信号列表，用户可点击从信号创建订单
  3. 用户在「订单执行」面板点击创建订单→系统弹出订单表单，用户填写标的、方向、数量、价格、类型
  4. 用户提交订单→系统更新订单列表，待执行订单数增加
  5. 用户在「持仓管理」面板查看持仓→系统展示持仓数量、成本、现价、市值、浮动盈亏
  6. 用户对持仓点击「交易操作」→系统触发卖出或加仓流程
  7. 用户在「风险控制」面板设置止损/止盈百分比→系统根据持仓与风险规则计算实时预警，展示风险预警数量
  8. 用户取消某笔待执行订单→系统从订单列表移除该订单，更新统计卡片
交易流程当前为框架态，订单创建/取消逻辑待实现（TODO），但界面交互流程已完整

6. 研究报告生成（输出舱）

入口：输出舱 → 研究报告 核心：ResearchReportPage 状态：scoreDocStore
  1. 用户进入「研究报告」页→系统加载可生成报告的股票列表
  2. 用户从下拉框选择股票→系统将该股票写入 store.symbol，并加载该股票的历史报告版本
  3. 用户点击「生成报告」→系统调用评分文档服务生成 VN 版本研究报告，进入生成中状态
  4. 系统生成完成后 Toast 提示成功→系统自动刷新版本列表，最新报告置顶展示
  5. 用户在报告列表中查看 Markdown 内容预览→系统渲染报告正文
  6. 用户点击「下载」→系统将 Markdown 报告打包下载为 `{symbol}_V{version}_研究报告_{scoreDate}.md`
报告版本基于 docId + version 管理，持久化在 IndexedDB。
复核注：usePageGuard('research-report') 读取全局 pageStore.isClickable，初始为 true，默认不禁用生成按钮；仅在全局加载状态变化时才会禁用。

7. 驾驶舱 Dashboard

入口：驾驶舱 核心：CockpitShell 状态：widgetRegistry / MarketDataProvider
  1. 用户进入「驾驶舱」→系统加载已注册 Widget 实例，从 localStorage 恢复布局
  2. MarketDataProvider 启动市场数据订阅→系统向各 Widget 注入统一 marketData 上下文
  3. 系统按网格布局渲染 Widget→每个 Widget 通过 widgetEngine.mountInstance 异步挂载，展示大盘指数、板块热力图、资金流向、自选股、持仓概览、KAI 评分、AI 交易复盘等
  4. 用户拖拽/缩放 Widget→系统保存新布局到 localStorage，并记录日志
  5. 用户点击「添加 Widget」（当前仅 UI 占位）→按钮暂无 onClick 处理，交互逻辑待实现；Widget 实例当前由 WidgetRegistry 构造函数默认注册
  6. 单个 Widget 加载失败→WidgetErrorBoundary 捕获异常，展示错误状态与重试按钮，不影响全局
  7. 用户点击「返回首页」→系统卸载 Widget 实例，清理资源
新增 Widget 必改三处：widgetRegistry.ts、DEFAULT_WIDGET_CONFIG、WIDGET_DEFAULT_DATA_SOURCE；组件消费 useMarketData()

8. 智能体管理（总控舱）

入口：总控舱 → 智能体总控台 核心：AgentHubPage / AgentTriggerPage / AgentRegistryPage 状态：agentStore / agentRuntime
  1. 用户进入「智能体总控台」→系统展示已注册智能体数、运行中/已完成/失败任务统计
  2. 用户点击「智能体注册表」→系统展示所有已注册 Agent 的配置与能力
  3. 用户点击「任务触发」→系统进入触发配置页
  4. 用户选择智能体 → 选择 MCP Server → 选择 Tool→系统自动根据 Agent 元数据回显默认 Server 与 Tool
  5. 用户填写 Payload（JSON）、超时时间→系统实时校验 JSON 格式，错误时提示
  6. 用户点击「执行任务」→agentRuntime.execute 调用对应 Tool，任务进入执行中状态；任务状态通过 eventBus 广播，AgentTasksPage 订阅 AGENT_TASK_* 事件同步更新
  7. 系统返回执行结果→成功：展示 JSON 结果；失败：展示错误信息
  8. 用户进入「任务列表 / DAG 调度器 / 能力图谱」→系统展示任务执行状态、DAG 工作流或智能体能力依赖关系
智能体管理还包含 LLM 管理、API 配置、模型升级、Skill 核查、数据标签、反馈控制台等 Phase E/F 模块
