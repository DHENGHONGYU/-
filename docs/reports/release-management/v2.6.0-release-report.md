## 发布说明

本次 Release 针对 V9 投研系统数据链路中 3 个核心文件的 `?? 0` 隐式兜底模式进行了全面整改。当上游数据源返回 `null`/`undefined` 时，原代码会静默替换为 `0`，导致下游盈亏计算、排名、评分产生误导性结果。

## 核心变更

| 文件 | 变更 | 说明 |
|------|------|------|
| `src/store/positionPoolStore.ts` | `quantity/avgCost/currentPrice ?? 0` → `?? Number.NaN` | NaN 显式空值标记 |
| `src/data/sectorDefinitions.ts` | `v6Composite ?? 0` → `?? Number.NaN` | NaN 显式空值标记 |
| `src/store/profileStore.ts` | `qualityScore ?? 0` → `?? 50` | 中值兜底 + `minQuality > 0` → `minQuality !== undefined` |
