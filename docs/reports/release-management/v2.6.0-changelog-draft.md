# V9 Release v2.6.0 — 零值兜底整改与自动推送工具链

> **Release Date**: 2026-07-26  
> **Branch**: `feat/cross-index-20260719`  
> **Tag**: `v2.6.0`  
> **Type**: Bug Fix + Data Quality + DevOps Tooling

## 概述

本次 Release 包含两大核心交付：

1. **零值兜底整改** — 消除 3 个核心模块中 `?? 0` 隐式兜底，改用 `Number.NaN` 显式标记缺失值，确保数据链路中缺失值与业务零值可区分
2. **自动推送工具链** — 新增 `GitAutoPush` PowerShell 模块、定时任务脚本、Pester 单元测试和 CI/CD 工作流，解决网络不稳定场景下的远程同步问题

## 自动推送工具链

### 新增文件

```

│   ├── GitAutoPush.psm1              # 可复用 PowerShell 模块（8 个导出函数）

├── tests/

.github/workflows/
└── git-auto-push.yml                 # CI/CD 工作流
```

### GitAutoPush 模块 API

| 函数 | 说明 |
|------|------|
| `Invoke-AutoPush` | 完整自动推送流程（检测→推送→验证） |
| `Test-GitNetwork` | 检测 GitHub 443 端口连通性 |
| `Get-PendingCommits` | 获取待推送 commit 列表 |
| `Test-TagNeedsPush` | 检查 Tag 是否需要推送 |
| `Push-BranchWithRetry` | 带重试的分支推送 |
| `Push-TagWithRetry` | 带重试的 Tag 推送 |
| `Test-RemoteSync` | 验证远程与本地同步状态 |
| `Write-GitLog` | 统一日志输出（控制台 + 文件） |

### 核心功能

- **网络检测**：`Test-NetConnection` 检测 GitHub 443 端口，支持自定义间隔和超时
- **智能推送**：自动检测 pending commits 和未同步的 Tag，按需推送
- **重试机制**：分支推送和 Tag 推送各支持独立的重试次数和间隔
- **同步验证**：推送完成后自动验证远程与本地状态
- **日志追踪**：所有操作同时输出到控制台和日志文件
- **多场景支持**：开发机前台运行、Windows 计划任务、CI/CD 集成

### 单元测试覆盖

| 测试场景 | 测试内容 |
|----------|----------|
| Module Loading | 模块导入、8 个函数导出验证 |
| Write-GitLog | INFO/WARN/ERROR/SUCCESS 四级日志 |
| Test-GitNetwork | 连通性、不可达主机、超时处理 |
| Network Fluctuation Simulation | 隔离仓库、pending 检测、tag 检测、推送失败重试 |
| Retry Mechanism | 分支/tag 推送重试计数、耗时验证 |
| Invoke-AutoPush Integration | 网络不可达返回码、空工作检测、完整流程 |
| Edge Cases | 不存在路径、空仓库、无远程等异常 |

### CI/CD 集成

`git-auto-push.yml` 工作流支持：

| 触发方式 | 说明 |
|----------|------|
| `workflow_dispatch` | 手动触发，支持自定义 branch/tag/interval |
| `schedule` | `cron: '*/5 * * * *'` 每 5 分钟自动检查 |
| `push` | `feat/**` / `feature/**` 分支推送触发 |

| Job | 说明 |
|-----|------|
| `test` | Pester 单元测试，生成 NUnit XML 报告 |
| `auto-push` | Windows runner 执行 `Invoke-AutoPush` 完整流程 |
| `verify-only` | Dry-run 模式，仅检查同步状态 |
