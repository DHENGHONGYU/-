1. **测试覆盖率对比 ×2**：`test-coverage-comparison-v2.2.1.md`（275 行）与 `v2.2.1-test-coverage-comparison.md`（1135 行）**头部不同、内容重叠**，均比对 v2.2.0↔v2.2.1。明显为同一主题的两份不同演进稿，**应合并或标注主从**，否则读者不知以哪份为准。
2. **UI 差异比对 ×3**：`v6pro-ui-page-diff-report`(06-24)、`v6-v9-ui-component-comparison`(07-01)、`v6pro-v9-gap-analysis`(07-02) 三份都做「V6/V6Pro ↔ V9」比对，角度不同（页面结构 / 组件库 / 架构全量），但**结论易互相打架**（如组件数 38、Widget 9/18、缺失项口径不一），需一份「唯一权威迁移基线」统领。
3. **综合审计 ×3+**：`audit-findings-2026-07-05`、`2026-07-07-comprehensive-audit-report`、`changelogs/2026-07-05-comprehensive-audit-and-remediation` 时间相邻、主题相近，**存在结论重叠风险**。
4. **架构分析 ×2**（06-27）：覆盖报告与代码实现报告高度同源（同 28 模块同评分），两份并列增加维护成本。
