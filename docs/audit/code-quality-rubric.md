# 代码质量量化考核标准（v1.0）

> 本标准基于项目 Hard Constraints 和 Engineering Conventions 制定，量化考核 6 大维度。

## 一、硬编码检测（Critical）

### 1.1 Magic Numbers（禁绝）
- **规则**：数值字面量不得直接出现在业务逻辑中
- **白名单**：`0`、`1`、`-1`、`100`（百分比基础）、`true`/`false`
- **检测模式**：`/\b\d{2,}\b/`（2位及以上数字）排除白名单
- **阈值**：0 个
- **例外**：配置文件（`/config/`）、常量枚举（`*.constants.ts`）、测试文件

### 1.2 Magic Strings（禁绝）
- **规则**：字符串字面量不得直接出现在业务逻辑中
- **白名单**：`''`、`' '`、`'.'`、`'/'`、`'\n'`
- **检测模式**：单引号/双引号包裹的非空白字符串，length > 2
- **阈值**：0 个
- **例外**：JSX 渲染文本、错误消息模板（需在 `/constants/` 中定义）

### 1.3 Magic Arrays/Objects（禁绝）
- **规则**：内联数组/对象字面量超过 3 项必须提取为常量
- **检测模式**：数组字面量 `\[.*,.*,.*\]` 长度 > 3
- **阈值**：0 个

## 二、循环嵌套深度（Critical）

### 2.1 Nesting Depth（禁 >3 层）
- **规则**：`for`/`while`/`forEach`/`map`/`filter`/`reduce` 嵌套不得超过 3 层
- **检测**：AST 遍历，计数嵌套层级
- **阈值**：0 个函数超过 3 层

### 2.2 Callback Hell（禁绝）
- **规则**：Promise `.then().then()` 或 async/await 嵌套不得超过 3 层
- **阈值**：0 个函数超过 3 层

## 三、圈复杂度（Cyclomatic Complexity）

### 3.1 函数复杂度
- **规则**：每个函数的圈复杂度（决策点数量）不得超过 10
- **计算**：`1 + 分支数量`（if/else/switch/case/三元/?./catch/&&/||）
- **阈值**：0 个函数超过 10
- **高风险**：15 < complexity ≤ 20，**严重**：> 20

### 3.2 函数长度
- **规则**：每个函数不得超过 50 行（不含注释和空行）
- **阈值**：0 个函数超过 50 行

## 四、错误处理完整性

### 4.1 Async 函数必须有 try-catch
- **规则**：`async function` 体内必须有 `try-catch` 块
- **阈值**：0 个 async 函数缺少 try-catch
- **例外**：React Query / SWR 的 queryFn（框架自行处理）

### 4.2 Error 边界检测
- **规则**：`throw new Error` 必须携带有意义的 message
- **阈值**：0 个 throw 缺少 message

### 4.3 .catch() 完整性
- **规则**：`Promise.then()` 之后必须有 `.catch()` 或 `try-catch`
- **阈值**：0 个未捕获的 Promise rejection

## 五、类型安全

### 5.1 `any` 类型（禁绝）
- **规则**：业务代码中禁止使用 `: any` 类型注解
- **检测模式**：`:\s*any\b`（排除 `Array<any>`、`Promise<any>` 等泛型）
- **阈值**：0 个
- **例外**：`catch (e: any)`、第三方库声明文件（`.d.ts`）

### 5.2 强制类型转换
- **规则**：`as` 强制类型转换每文件不得超过 3 次
- **检测模式**：`\s as\s+\w+`
- **阈值**：每文件 ≤ 3 个

## 六、代码重复

### 6.1 重复代码块
- **规则**：超过 6 行完全相同的代码块应提取为函数
- **阈值**：0 个 6+ 行重复块

## 量化评分体系

| 维度 | 权重 | 优秀 | 合格 | 警告 | 违规 |
|------|------|------|------|------|------|
| Magic Numbers | 20% | 0 | 1-3 | 4-10 | >10 |
| Magic Strings | 15% | 0 | 1-3 | 4-10 | >10 |
| Nesting Depth | 25% | 0 | 0 | 1-2 | >2 |
| Complexity | 20% | 0 | 0 | 1-2 | >2 |
| Error Handling | 10% | 0 | 1-2 | 3-5 | >5 |
| Type Safety | 10% | 0 | 1-3 | 4-5 | >5 |

**总评分** = Σ(维度得分 × 权重)，优秀 ≥ 90，合格 ≥ 70，警告 ≥ 50，违规 < 50
