### 3.1 分级标准

| 等级 | 定义 | 判断标准 |
|:---|:---|:---|
| **P0 - 核心关键** | 系统运行不可或缺的实体，损坏将导致核心功能瘫痪 | 影响股票池、评分、交易等核心业务流 |

| **协议目的** | 跨模块写操作的统一数据封装格式，确保可追溯、可审计 |
| **结构组成** | `meta`（元数据） + `payload`（业务数据） |
| **Meta 字段** | source / target / action / traceId / timestamp（共5个必填） |
| **目标类型** | 9种（db / analyzer / ui / tradinghub / system / strategy:hotSector / strategy:valuePit / strategy:rotationSignal 等） |
| **动作类型** | 30+种（INSERT_STOCK / UPDATE_STOCK / SAVE_SCORES / TRADE_ACTION_EXECUTED 等） |
| **来源模块** | 11种（fetcher / stockpool / analyzer / tradinghub / system / user / rotation / sector / news / trading / strategy） |
| **验证机制** | EnvelopeFactory.validate() — 7项校验规则 |
| **关联机制** | traceId 全链路追踪 |
