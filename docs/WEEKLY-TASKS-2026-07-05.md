## 🔧 故障排查

### Husky 钩子未触发

**症状**: `git commit` 时未运行检查

**方案**:
```powershell
# 临时方案：手动运行检查
npm run pre-review

# 提交
git commit --no-verify -m "message"
```

**长期方案**: 调试 Husky 安装问题

### pre-review 检查失败

**症状**: 检查项失败

**方案**:
1. 查看输出，定位失败项
2. 逐个修复
3. 重新运行 `npm run pre-review`

### Commitizen 交互式提交卡住

**症状**: `npm run commit` 无响应

**方案**:
```powershell
# 手动提交
git commit -m "feat: 简短描述

详细描述

Closes #123"
```
