# V6 模型规格附录（v4.3 完整规格）

> 本文档从 `v6-stock-analysis-model` SKILL §六 提取，作为 Phase 1~7 的执行依据。

## 模型总览

V6是一条**漏斗式分层打分流水线**：L-1→L0→L8每层产出【定性结论 + 标准化层得分(0-5)】，最后按权重合成综合分，映射评级，并由情景推演推导目标价。

**v3.0 新增 L-1 层（行业评分估值）**：调用 `industry-score-mapping` 技能，从预制行业分析报告中自动提取 SKILL-C/SKILL-N 评分并注入个股分析。

**v4.0 PRD合规升级**：基于《股票分析模型V6产品需求文档》复核，新增数据字典、因子体系（财务/量价/另类）、核心跟踪指标、主题框架可插拔机制、Point-in-time防未来函数、置信度标注。

**v4.1 筹码变化度模块**：L8层新增「持股人数变化」为核心的八级量化衍生指标体系。

**v4.2 置信度考核体系**：数据来源可信度分级(A-E) → 证据充分度评分(ESS) → 七级置信度判定 → 数据时效性折损 → 层级聚合 → 综合报告置信度。

**v4.3 业绩兑现临界点**：L3层新增三维交叉验证框架 — OCR + MCE + TIMS → IPC。

```
L-1行业 → L0宏观 → L1护城河 → L2竞品 → L3财务/估值 → L4情景
                         ↘ L5 T-M → L6 Hype → L7第二曲线 → L8技术筹码
                                             ↓
                                     加权合成 → 综合分(0-5)
                                             ↓
                                 评级映射 + 目标价推导 + 跟踪仪表盘
```

## 确定性层 vs LLM层 划分

| 类型 | 层/字段 | 说明 |
|------|---------|------|
| **确定性（程序直算）** | L3财务比率、估值倍数；L4市值=净利×PE；L8技术指标/资金/融资 | 可复现、可单测 |
| **LLM + 人工复核** | L0强度、L1护城河、L2竞品对比、L5/L6成熟度与阶段、L7叙事与主题契合、L4概率与催化 | 需引用证据、强制留痕 |

## 逐层分析规格

> 完整逐层规格（L-1 至 L8）含评分 Rubric、数据字典、自动化程度标注，共 ~750 行。
> 因篇幅限制，此处保留结构索引，完整内容见 SKILL 原文 §六 或历史版本。

### 结构索引

| 层 | 核心内容 | 关键公式/框架 |
|----|---------|-------------|
| L-1 | 行业评分估值 | SKILL-C 加权总分 × 关联度系数 + SKILL-N 额外加分 |
| L0 | STEEP 宏观扫描 | 子项均值/2 → 归一化 0-5 |
| L1 | 护城河分析 | 五类型识别（技术/客户/规模/网络/资源）→ 强度→层得分 |
| L2 | 竞品分析 | 技术代差+份额+客户认证 加减分 |
| L3 | 财务与估值 | 四维 Rubric + IPC 三维框架（OCR/MCE/TIMS） |
| L4 | 情景推演 | 概率加权合理价 + 收益比 |
| L5 | T-M矩阵 | (技术+市场)/200 × 5 |
| L6 | Hype Cycle | 五阶段定位 |
| L7 | 第二曲线 | 生命阶段诊断 + 催化剂★ |
| L8 | 技术筹码 | 量价因子 + 筹码变化度八级指标（SCD→CSR） |

### IPC 临界点综合判断（v4.3 核心）

```
临界点距离得分 = OCR得分 × 0.35 + MCE得分 × 0.30 + TIMS矩阵分 × 0.35

临界点阶段判定：
  ≥ 4.5 → ✅ 临界点已突破（L3 +1.0）
  3.5-4.4 → 🔶 临界点附近（L3 +0.5）
  2.5-3.4 → 🔸 临界点前夜（L3 +0.0）
  1.5-2.4 → 🔹 临界点遥远（L3 -0.5）
  < 1.5 → ⬜ 未到临界点（L3 -1.0）
```

### 筹码变化度八级指标（v4.1 核心）

| 级别 | 指标 | 核心公式 |
|------|------|---------|
| 1级 SCD | 持股人数变化率 | (本期-上期)/上期×100% |
| 2级 PCH | 人均持股变化 | 流通股本/股东人数 |
| 3级 AII | 庄家吸筹强度 | \|SCD\|/\|股价涨跌幅\| |
| 4级 | 筹码博弈矩阵 | 股价方向 × 股东人数方向 → 6态 |
| 5级 RSI | 散户游资辨识度 | 股东人数增长率 - 人均持股增长率 |
| 6级 CCS | 筹码锁定-分散周期 | 连续2-4期方向判断 |
| 7级 DIV | 筹码集中度-股价背离度 | 符号×\|SCD-股价涨跌幅\| |
| 8级 CSR | 筹码系统性风险预警 | (当前/历史最低-1)×100% |

## 置信度考核体系（v4.2）

### 数据来源等级

| 等级 | 可信度 | 典型来源 | 权重 |
|:---:|:---:|------|:---:|
| A | 极高 | 统计局/海关/专利局 | 1.00 |
| B | 高 | 审计年报/招股书 | 0.90 |
| C | 中高 | 行研报告/券商研报 | 0.78 |
| D | 中 | 调研纪要/专家访谈 | 0.60 |
| E | 低 | 媒体/推测/论坛 | 0.40 |

### 置信度判定

```
ESS = Σ(来源权重 × 数量系数) / 最低证据数
★★★★★ = ESS≥1.20 | ★★★★ = 1.00-1.19 | ★★★☆ = 0.80-0.99
★★☆☆ = 0.60-0.79 | ★☆☆☆ = 0.40-0.59 | ☆☆☆☆ = 0.20-0.39 | N/D = <0.20
```
