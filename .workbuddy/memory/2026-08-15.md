- CLI 安装：`tencent-news-cli` 官方安装脚本 `setup.ps1` 用 `irm|iex` 被沙箱安全策略拦截（iex 执行任意代码）。改用：下载脚本到本地 → 因无 BOM 被 PowerShell 按 GBK 读致中文行解析失败 → 补 UTF-8 BOM 后可直接 `&` 运行；其内部 `curl.exe` 失败触发 `$ErrorActionPreference=Stop` 终止，fallback(Invoke-WebRequest) 未执行。最终手动实现下载+SHA256校验(`checksums.txt` 匹配 `windows-amd64/tencent-news-cli.exe`)+落盘 `%HOME%/.tencent-news-cli/bin/`+写用户 PATH，版本 v1.0.14 校验通过。
- **编码关键教训**：`tencent-news-cli` 输出是 **UTF-8**（非 GBK）。PowerShell 重定向时用系统码表(GBK)解码 UTF-8 字节 → 乱码；用 Python `subprocess` 抓原始字节按 `utf-8` 解码正常。取数一律走 Python，不要走 PowerShell `Out-File`。提示信息走 STDERR、数据走 STDOUT。
- 子命令面：`hot`/`search <kw> --limit N`(核心:行业资讯检索)/`morning`/`evening`/`jiaozhen`(事实核查)/`weather`/`apikey-*`。
- **阻塞项（未解决）**：API Key 必填。用户选"已配置/另有通道"，但 `apikey-get`→exit 2「未设置 API Key」，且 `.tencent-news-cli` 目录无配置文件、仅存在无关环境变量 `TENCENT_DOCS_LOCAL_MCP`(腾讯文档本地MCP)。真实采集待用户粘贴 Key（news.qq.com/exchange?scene=appkey）后 `apikey-set` 再跑 `_tmp_verify/tn_collect.py`（已备好，覆盖数据采集/数据要素/金融科技/财经/AI数据/算力/科技 七主题 + hot/morning/evening）。
