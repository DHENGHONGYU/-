## 测试发现并修复的 2 个真实 Bug

### Bug 1：StockSearch 下拉不渲染（getMarketLabel 空指针）
- `src/components/organisms/input/StockSearch.tsx` 的 `getMarketLabel(industry)` 对 `undefined` 调用 `.toUpperCase()` 抛错
- 真实数据流中 `industry` 来自 `inputService.searchStocks` 返回的 `m.market`（SH/SZ/HK），但测试 mock 用 `market` 字段 → `industry` 为 undefined → 渲染崩溃
- 修复：`getMarketLabel(industry: string | undefined)` 增加空值守卫，返回「—」占位标签

### Bug 2：inputHubStore.searchStocks 阻塞/抛错
- 初版改为 `async` 后在方法体内裸调用 `refreshExistingSymbols()`（兄弟 store 方法，不在作用域）→ `ReferenceError: refreshExistingSymbols is not defined`，整个搜索 reject，下拉永远不展开
- 根因关联：store 的 searchStocks 原会 `await listStocks()`（真实 dataBridge.query），在 jsdom 中挂起 → 搜索无响应
- 修复：移除方法内对 `refreshExistingSymbols` 的裸调用；existingSymbols 由组件 mount 时 `refreshExistingSymbols()` 刷新（fire-and-forget，不打断搜索）

- Tushare Pro HTTP 接口是**根路径** `https://api.tushare.pro`（POST，无 /api 后缀）。
