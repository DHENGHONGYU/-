### 关键工具坑（重要可复用）
- **IDE ESLint `no-unused-vars` "fix on save" 会自动剔除尚未被使用的 import**：若先加 import 再加用法，linter 会在两次编辑之间把 import 删掉，导致后续 Edit 报 "File has been modified since read" 反复失败。本次 `index.ts` 因此被回退多次。
- **解法**：对需要同时加 import + 用法的文件，用 `Write` 一次性原子重写整文件（import 与用法同批存在，linter 不删），避免分步 Edit 被 linter 穿插回退。对并行 Agent 活跃编辑的共享文件（如本例曾试改 `data-dictionary.ts`），严格只读核查、不抢改。
