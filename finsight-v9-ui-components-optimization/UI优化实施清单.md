## 一、色阶系统

### 1.1 表面四级层级（必做）

- [x] 建立四级表面变量：`--v9-background` → `--v9-card` → `--v9-popover` → `--v9-surface-3`
- [x] 卡片统一使用 `--v9-card`，禁止直接使用 `--v9-background` 作为卡片底色
- [x] 浮层（下拉/气泡/弹窗内容）使用 `--v9-popover`，与卡片形成 4-5% 亮度差
- [x] 深色模式下边框亮度不低于 24%，保证边界可辨

### 1.2 表格色阶（必做）

- [x] 表头背景 = `--v9-muted` / 30%，底部加 1px border
- [x] 行分割线 = `--v9-border`
- [x] 行悬停 = `--v9-surface-2`（明显可辨，不刺眼）
- [x] 斑马纹 = 极浅 alpha（浅色 2% / 深色 2%），仅作辅助，不做主要区分
- [x] 行选中 = `--v9-primary` / 3% 微蓝色底
- [x] 底部分页栏 = `--v9-muted` / 20% + 顶部 border，与表格体形成层级差
- [x] 禁用行 = `opacity-60`，不单独改背景

### 1.3 状态色使用（必做）

- [x] 状态徽章/横幅统一使用：低浓度背景（8-15%）+ 同色边框（25-30%）+ 100% 图标文字
- [x] 禁止大面积实心状态色块（除了按钮和进度条）
- [x] 上涨/正向 = Success（绿色），下跌/负向 = Error（红色）
- [x] 警告/待审核/注意 = Warning（琥珀色），不使用红色，避免与红涨语义冲突

## 十二、通用规范

### 12.1 圆角（必做）

- [x] 控件默认 `rounded-md`（6-8px）
- [x] 卡片/浮层 `rounded-lg`（12-16px）
- [x] 徽章/开关 `rounded-full`
- [x] 小圆角 `rounded-sm` 用于复选框等小元素

### 12.2 间距（必做）

- [x] 4px 基础栅格
- [x] 控件内边距：py-2 px-3（8/12px）
- [x] 卡片内边距：p-6（24px）
- [x] 组件间距：gap-2 / gap-3 / gap-4

### 12.3 焦点可达（必做）

- [x] 所有交互元素 `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring`
- [x] 按钮额外 `ring-offset-2 ring-offset-background`
- [x] 表单元素聚焦时 border 同步变色

### 12.4 字体（必做）

- [x] 正文：Inter + Noto Sans SC
- [x] 数字/代码：`font-mono tabular-nums`
- [x] 价格、涨跌幅、计数等所有数值必须等宽对齐

### 12.5 阴影（必做）

- [x] 仅浮动层使用阴影（dropdown / popover / modal）
- [x] 卡片和表格仅用边框区分层级
- [x] 三级阴影：dropdown / popover / modal，强度递增

### 12.6 无障碍（必做）

- [x] 正文文字对比度 ≥ 4.5:1
- [x] 次要文字对比度 ≥ 3:1
- [x] 图标按钮有 aria-label
- [x] 纯图标操作有 tooltip
- [x] 支持键盘导航（Tab / Enter / Esc）
