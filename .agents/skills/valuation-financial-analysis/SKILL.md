# 估值与财务分析模型 — v1.0.6

> **版本**: v1.0.6 | **日期**: 2026-08-21 | **校验基准**: FinSightV9 code_version 2.0.0-rc.1
> **任务性质**: SOP 执行（财务+估值双模型编排），允许输出财务评分+估值评分+情景目标价，禁止跳过红黄预警、禁止用单一估值法不交叉验证
> **输出格式**: 阶段化 SOP 矩阵 + 财务健康度摘要 + 估值评分卡 + 三情景目标价推导结果 + 风险预警清单

## 一、触发条件（Invoke When · RULE-TPL 三标签标注：显式触发 / 脚本/审计触发 / 设计/协议触发）

- **显式触发 1**：用户明确要求「财务分析」「估值模型」「valuation」「target price」「目标价推导」「计算 PEG/DCF」；或评估公司财务健康度、构建三情景推导目标价、检查财务红黄预警信号
- **显式触发 2**：怀疑出现财务红色/黄色预警信号（经营现金流负、应收增速 > 营收增速 50% 等）；或公司发布年报/季报（近 2 年 + 最新一期）需要刷新财务评分
- **脚本/审计触发 3**：`v6-stock-analysis-model` 执行 L3 财务/估值层，需要确定性财务指标计算（上游联动）；或 `intelligent-score` 执行九维评分的估值/盈利/质量维度需要程序直算的确定性分数（上游联动）
- **脚本/审计触发 4**：`npm run audit:skill-coverage` 报告估值注册表漂移；或 vitest 中财务阈值/估值基准快照断言不通过；或 `npm run tsc:prod` 报估值类型错误
- **设计/协议触发 5**：4 大类 15 指标财务阈值表（毛利率/净利率/ROE/ROIC 等）版本变更后存量结论重评；三情景净利假设框架 / 催化剂量化标准版本升级；行业基准估值表（创新药/半导体/新能源等 8 行业 PE/PEG/PB 区间）更新后存量估值结论回溯；V6 L3c IPC 业绩兑现临界点三维框架版本调整后财务指标映射重评

**不触发场景**（减少误激活，至少 2 条）：
- 纯行业/板块层面的估值水位分析（走 `sector-analysis-framework`）
- 纯技术筹码分析（走 V6 L8，不在本 Skill 范围）

**协作 Skill（链式调用，至少 1~3 个）**：
- `v6-stock-analysis-model`：本 Skill 作为 L3a/L3b 层确定性输入，并对接 L3c IPC 业绩兑现临界点
- `intelligent-score`：九维估值/盈利/质量维度确定性分数供给
- `audit:skill-coverage`：完成后核验注册完整性

## 三、阶段化 SOP（按 Phase 0~N 组织，**每阶段必写目标 + 交付物清单 + 代码/文档模板**）

### Phase 0 — 财务指标计算与趋势判定

**目标**：对 4 大类 15 个财务指标程序化计算，并判断其趋势（触底反转/稳健增长/修复中/恶化/严重恶化）。

**交付物**：
1. **4 类 15 指标健康阈值表**：
   ```
   盈利能力（4）：毛利率>30% / 净利率>10% / ROE>15% / ROIC>10%
   成长能力（3）：营收增>15% / 净利增>20% / 订单增>20%
   运营效率（3）：应收周转<90天 / 存货周转<60天 / 经营现金流/净利>80%
   财务安全（4）：资产负债率<60% / 流动比率>1.5 / 利息保障>5 / 商誉/净资产<30%
   ```
2. **5 档趋势判定**（触底反转5/稳健增长4/修复中3/恶化2/严重恶化1）：
   - 触底反转：连续两季改善 + Q1/Q2 环比转正 → 5 分
   - 稳健增长：增速稳定，波动<20% → 4 分
   - 修复中：下滑趋缓，边际改善 → 3 分
   - 恶化：连续下滑，无改善 → 2 分
   - 严重恶化：亏损扩大 + 现金流失血 → 1 分

### Phase 1 — 红黄预警扫描

**目标**：扫描 10 类预警信号，标注红色（立即关注，L3 评分自动降 1 分）和黄色（密切跟踪，标注）。

**交付物**：
1. **红色预警（5 类，触发任一降 1 分）**：
   ```
   经营现金流连续两季为负
   应收账款增速 > 营收增速 50%+
   存货周转天数同比延长 > 30 天
   大股东质押 > 50%
   审计报告非标意见
   ```
2. **黄色预警（5 类，触发需标注）**：
   ```
   毛利率连续两季下滑
   有息负债增速 > 资产增速
   商誉/净资产 > 30%
   关联交易占比 > 20%
   客户集中度 TOP5 > 50%
   ```

### Phase 2 — 多方法估值交叉验证

**目标**：用相对估值（PE/PEG/PB/EV-EBITDA）+ 绝对估值（DCF/DDM）至少 3 种方法交叉验证，综合决定估值水位评分。

**交付物**：
1. **估值方法矩阵（6 种适用场景）**：
   ```
   PE：通用，尤其消费/制造业 → 合理 PE = 行业基准 × (1+成长性溢价-风险折价)
   PEG：成长股判断低估与否 → <0.5显著低估 / 0.5-1低估 / 1-1.5合理 / ≥1.5高估
   PB：重资产/金融 → 合理 PB = ROE/要求回报率
   EV/EBITDA：资本密集型（去除资本结构影响）
   DCF：稳定现金流成熟企业 → 计算 FCF_t / (1+WACC)^t + 终值
   DDM：高分红公用事业类 → D_1/(r-g)
   ```
2. **三维度估值评分 Rubric（每项 1-5）**：
   ```
   绝对估值：PEG<0.5→5 / 0.5-0.75→4 / 0.75-1.25→3 / >1.5→≤2
   相对行业：折价>30%→5 / 10-30%→4 / 平价→3 / 溢价>20%→≤2
   历史分位：<20%→5 / 20-40%→4 / 40-60%→3 / >60%→≤2
   估值综合 = 三项平均
   ```
3. **IPC 业绩兑现临界点**（对接 V6 v4.3 L3c）：
   - 三维交叉：订单覆盖率 OCR × 0.35 + 0-1 事件 MCE × 0.30 + 技术迭代×市占率 TIMS × 0.35
   - 阶段映射：≥4.5 → 临界点已突破（L3 财务评分 +1.0）/ 3.5-4.4 → 最佳击球区（+0.5）/ 2.5-3.4 → 临界点前夜（+0.0）/ <1.5 → 未到（-1.0）

### Phase 3 — 三情景目标价推导

**目标**：构建上行/基准/下行三情景（概率 + 净利假设 + 估值倍数），推导概率加权合理价与目标价区间。

**交付物**：
1. **三情景构建模板**：
   ```
   上行情景（20-30%概率）：催化剂兑现 → 净利基准×(1.3-1.5) + 行业高位PE
   基准情景（50-60%概率）：正常经营 → 趋势外推净利 + 行业中位PE
   下行情景（15-25%概率）：风险暴露 → 净利基准×(0.6-0.8) + 行业低位PE
   ```
2. **目标价公式（PRD 标准化）**：
   ```
   概率加权合理价 = Σ(情景股价中枢 × 概率)
   目标价区间下沿 = 基准情景股价上沿
   目标价区间上沿 = 上行情景股价下沿
   收益风险比 = ((上行目标价 - 当前) × 上行概率) / ((当前 - 下行目标价) × 下行概率)
   ```
3. **评分Rubric**：基准隐含空间>20%且收益比>2 → 4-5分；10-20%空间 → 3.5-4分；基准无空间或下行大 → ≤3分

## 四、陷阱与经验教训（**至少 6 条，基于实战提炼，禁止空话**）

| # | 陷阱 | 后果 | 规避 |
|---|------|-----|-----|
| 1 | 单一估值法（PE）拍板，不做 PEG/PB/DCF 交叉验证 | 周期股用 PE 被严重误判（高 PE 反而是低估期） | Phase 2 强制 ≥3 种估值方法；对周期股优先 PEG/资产重估值 |
| 2 | 财务预警只打分不标注理由 | 降分后找不到依据，置信度降级 | Phase 1 红黄预警每项触发后必须写出具体数字（如「应收增 82% vs 营收增 15%，超 50% 阈值 → 红警降 1 分」） |
| 3 | DCF 假设 WACC/g 不合理（如永续 g=5%） | 终值严重虚高，目标价虚浮 | 强制 WACC 范围：8%-13%；永续 g 上限 = GDP 名义增速（≤ 4%）；超范围时警告并拒绝输出 |
| 4 | IPC 临界点分和 L3 财务分叠加后溢出（超 5 分或 <1 分） | 评分夹取不及时，评分溢出失真 | Phase 2 IPC 调整后最后一步执行夹取 `score = clamp(score, 1.0, 5.0)` |
| 5 | 行业基准库缺失标的行业 | 估值水位无锚可依（如半导体用消费行业 PE 基准） | §二前置检查第 3 步：标的行业不在 8 行业 → 归为「通用」基准，并在输出显式标注「通用基准近似，建议人工复核」 |
| 6 | 三情景概率之和 ≠ 100%（如 25%+55%+15%=95%） | 概率加权合理价计算失真 | Phase 3 生成前断言：abs(上行+基准+下行-1.0) < 0.001；否则 FAIL 重试 |
| 7 | 商誉/净资产 >30% 只标黄不减分，导致爆雷前估值偏高 | 踩雷后估值大幅回调；但红警 5 类中未包含商誉 | Phase 1 中「商誉/净资产 > 50%」追加为隐性红警（额外降 0.5 分）；>30% 标黄不变，符合 §红黄预警定义 |
| 8 | 强周期行业（煤炭/钢铁/航运/有色/油气）用单一年度 ROE / FCF / 净利润计算估值 | 周期顶点高利润期单一年 PE 反而「低」，被误判为低估；实际周期下行利润暴跌，会深度套牢 | §二前置检查识别强周期行业；Phase 2 估值环节中，周期股强制使用「近 5 年滚动平均 ROE」「近 5 年平均经营现金流/FCF」作为估值模型输入分子，单一年指标仅作附注辅助；输出显式标注「已按强周期 5 年均值修正」 |
