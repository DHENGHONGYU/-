# 估值与财务分析模型 (Valuation & Financial Analysis Model)

## 财务分析框架（2年1期）

### 核心财务指标清单

**盈利能力指标：**
| 指标 | 计算公式 | 健康阈值 | 分析意义 |
|------|---------|---------|---------|
| 毛利率 | (营收-营业成本)/营收 | >30% | 产品竞争力与定价权 |
| 净利率 | 净利润/营收 | >10% | 整体盈利能力 |
| ROE | 净利润/净资产 | >15% | 股东回报水平 |
| ROIC | 税后经营利润/投入资本 | >10% | 资本配置效率 |

**成长能力指标：**
| 指标 | 计算公式 | 健康阈值 | 分析意义 |
|------|---------|---------|---------|
| 营收增长率 | (本期营收-上期营收)/上期营收 | >15% | 业务扩张速度 |
| 净利润增长率 | (本期净利-上期净利)/上期净利 | >20% | 盈利增长质量 |
| 订单增长率 | (本期订单-上期订单)/上期订单 | >20% | 未来收入保障 |

**运营效率指标：**
| 指标 | 计算公式 | 健康阈值 | 分析意义 |
|------|---------|---------|---------|
| 应收账款周转天数 | 平均应收账款/日均营收 | <90天 | 回款效率 |
| 存货周转天数 | 平均存货/日均营业成本 | <60天 | 库存管理 |
| 经营现金流/净利润 | 经营现金流净额/净利润 | >80% | 盈利质量 |

**财务安全指标：**
| 指标 | 计算公式 | 健康阈值 | 分析意义 |
|------|---------|---------|---------|
| 资产负债率 | 总负债/总资产 | <60% | 财务杠杆风险 |
| 流动比率 | 流动资产/流动负债 | >1.5 | 短期偿债能力 |
| 利息保障倍数 | EBIT/利息费用 | >5 | 偿债安全性 |

### 财务趋势判断标准

| 趋势类型 | 判断标准 | 评分 | 投资策略 |
|---------|---------|------|---------|
| 触底反转 | 连续两季改善，且Q1/Q2环比转正 | 5分 | 积极加仓 |
| 稳健增长 | 增速稳定，波动<20% | 4分 | 持有 |
| 修复中 | 下滑趋缓，边际改善 | 3分 | 观望 |
| 恶化 | 连续下滑，无改善迹象 | 2分 | 减仓 |
| 严重恶化 | 亏损扩大，现金流失血 | 1分 | 回避 |

## 估值分析框架

### 相对估值法

**PE估值法：**
```
合理PE = 行业基准PE × (1 + 成长性溢价 - 风险折价)
目标价 = EPS × 合理PE
```

**PEG估值法：**
```
PEG = PE / 净利润增长率
判断标准：
- PEG < 0.5：显著低估
- 0.5 ≤ PEG < 1：低估
- 1 ≤ PEG < 1.5：合理
- PEG ≥ 1.5：高估
```

**PB估值法（适用于重资产/金融）：**
```
合理PB = ROE/要求回报率
目标价 = 每股净资产 × 合理PB
```

**EV/EBITDA（适用于资本密集型）：**
```
企业价值 EV = 市值 + 有息负债 - 现金
EV/EBITDA = EV / 息税折旧前利润
```

### 绝对估值法

**DCF现金流折现模型：**
```
企业价值 = Σ(自由现金流_t / (1+WACC)^t) + 终值/(1+WACC)^n

其中：
- 自由现金流FCF = 经营现金流 - 资本支出
- WACC = 股权成本×股权比例 + 债务成本×(1-税率)×债务比例
- 终值 = FCF_n × (1+g) / (WACC - g)
```

**DDM股利折现模型（适用于高分红）：**
```
股票价值 = D_1 / (r - g)
其中：
- D_1 = 预期下期股利
- r = 要求回报率
- g = 股利永续增长率
```

### 估值评分Rubric

| 估值维度 | 5分 | 4分 | 3分 | ≤2分 |
|---------|-----|-----|-----|------|
| 绝对估值 | PEG<0.5显著低估 | 低估 | 合理 | 高估 |
| 相对估值 | 相对行业折价>30% | 折价10-30% | 平价 | 溢价>20% |
| 历史分位 | <20%分位 | 20-40%分位 | 40-60%分位 | >60%分位 |

## 业绩兑现临界点判断 ★ v1.1 新增（对接 V6 v4.3 IPC）

> 投资的本质是对**未来业绩兑现**的定价。本模块与 `v6-stock-analysis-model` L3 层联动。完整框架见 V6 v4.3 SKILL-H 文档。

**三维度交叉验证**：

### 在手订单覆盖率 (OCR)
`OCR = 在手订单总额 / TTM营收` | ≥2.5x=超强覆盖 | 1.5-2.5x=强 | 0.8-1.5x=中等 | <0.3x=几乎无覆盖

### 0-1事件驱动市场空间 (MCE)
`MCE = 事件后TAM / 事件前TAM` | ≥10x=赛道级突破 | 3-10x=品类级 | 8种事件类型（首单/首发/海外/产能/资质/并购/政策/灯塔）

### 技术迭代 × 市占率 (TIMS)
`TIMS = 技术迭代系数 × 市占率提升系数` | 技术迭代←L1护城河+L5 T-M | 市占率←L2竞品分析

**跨层联动**：L1≥4→技术系数+0.2 | L7≥4→MCE+0.5 | L2≤2.5→市占率系数不取上限

### 综合临界点判定 (IPC)
`IPC = OCR×0.35 + MCE×0.30 + TIMS×0.35` — 对L3财务评分叠加 ±1.0 调整

| IPC | 阶段 | L3调整 |
|:---:|------|:---:|
| ≥4.5 | ✅ 临界点已突破 | +1.0 |
| 3.5-4.4 | 🔶 最佳击球区 | +0.5 |
| 2.5-3.4 | 🔸 临界点前夜 | +0.0 |
| <1.5 | ⬜ 未到临界点 | -1.0 |

## 情景推演模型

### 三情景构建框架

**上行情景（乐观）：**
- 假设：核心催化剂兑现，业绩超预期
- 概率：通常20-30%
- 净利润：基准×(1.3-1.5)
- 估值倍数：行业高位或溢价

**基准情景（中性）：**
- 假设：正常经营，业绩符合预期
- 概率：通常50-60%
- 净利润：基于当前趋势外推
- 估值倍数：行业中位数

**下行情景（悲观）：**
- 假设：风险暴露，业绩不及预期
- 概率：通常15-25%
- 净利润：基准×(0.6-0.8)
- 估值倍数：行业低位或折价

### 情景评分Rubric

| 情景特征 | 评分 | 说明 |
|---------|------|------|
| 基准隐含上行空间>20%且上行/下行收益比>2 | 4-5分 | 风险收益比优秀 |
| 上行空间10-20% | 3.5-4分 | 具备配置价值 |
| 基准已无空间或下行风险大 | ≤3分 | 谨慎或回避 |

### 目标价推导公式

**概率加权合理价：**
```
合理价 = Σ(情景股价中枢 × 概率)
```

**目标价区间确定：**
```
目标价区间下沿 = 基准情景股价上沿
目标价区间上沿 = 上行情景股价下沿
```

**示例：**
- 上行情景：股价120元，概率25%
- 基准情景：股价68元，概率60%
- 下行情景：股价42元，概率15%

计算：
- 合理价 = 120×0.25 + 68×0.60 + 42×0.15 = **77.1元**
- 目标价区间：**80-100元**

## 财务风险预警信号

### 红色预警（立即关注）
- 经营现金流连续两季为负
- 应收账款增速>营收增速50%以上
- 存货周转天数同比延长>30天
- 大股东高比例质押（>50%）
- 审计报告非标意见

### 黄色预警（密切跟踪）
- 毛利率连续两季下滑
- 有息负债增速>资产增速
- 商誉/净资产>30%
- 关联交易占比>20%
- 客户集中度（TOP5>50%）

## 使用示例

当用户要求"分析海目星财务情况"或"计算目标价"时：
1. 提取近2年+最新一期财报数据
2. 计算核心财务指标并判断趋势
3. 应用估值模型（PE/PEG/DCF等）
4. 构建三情景并推导目标价
5. 给出财务健康度和估值水平评分
