# 板块分析框架 (Sector Analysis Framework) — v1.0.6

> **版本**: v1.0.6 | **日期**: 2026-08-21 | **校验基准**: FinSightV9 code_version 2.0.0-rc.1
> **任务性质**: SOP 执行（六维度板块分析编排），允许输出综合评分卡与配置建议，禁止跳过任一维度就给结论、禁止政策信号不分级量化
> **输出格式**: 阶段化 SOP 矩阵 + 六维度评分卡（6 维度各 1-5 分+论据）+ 配置建议（超配/标配/低配）+ 跟踪指标清单

---

## 一、触发条件（Invoke When · RULE-TPL 三标签标注：显式触发 / 脚本/审计触发 / 设计/协议触发）

- **显式触发 1**：用户明确要求「板块分析」「六维度框架」「sector analysis」「行业板块」「板块轮动」「板块配置」；或在板块分析页面选择行业并触发六维度评估
- **显式触发 2**：需要判断某板块「超配/标配/低配」时；或国家级战略文件、部委规章、监管政策发布后需重评政策环境维度
- **脚本/审计触发 3**：成交量/机构持仓/板块相对强弱 三项任一项突破阈值（如成交量/60日均量 >150% 或 <60%）触发轮动信号；或 `npm run audit:skill-coverage` 报板块注册表漂移
- **脚本/审计触发 4**：`industry-score` 触发前需板块六维度结论作为输入时上游联动；或 vitest 中板块评分快照断言不通过
- **设计/协议触发 5**：六维度权重/政策分级量化表/国产化率-技术差距矩阵版本变更后存量结论重评；V6 模型 L0 宏观层与 L2 竞品层板块前提输入契约升级

**不触发场景**（减少误激活，至少 2 条）：
- 具体个股的基本面深度分析（走 `v6-stock-analysis-model`）
- 个股九维智能评分（走 `intelligent-score`）

**协作 Skill（链式调用，至少 1~3 个）**：
- `industry-score`：行业七维评分源（可消费板块六维度结论作为输入）
- `v6-stock-analysis-model`：L0 宏观与 L2 竞品层的板块前提输入
- `valuation-financial-analysis`：六维度「基金与估值」的估值方法参考
- `audit:skill-coverage`：完成后核验注册完整性

## 三、阶段化 SOP（按 Phase 0~N 组织，**每阶段必写目标 + 交付物清单 + 代码/文档模板**）

### Phase 0 — 六维度数据收集与证据整理

**目标**：按板块轮动信号/政策环境/外部竞争/技术跃迁/下游市场/基金估值 六个维度分别收集证据并标注来源等级（A/B/C/D/E）。

**交付物**：
1. **六维度证据清单**（每维度 ≥2 条证据，标注来源等级）：
   ```
   维度一 轮动信号：
   - 成交量/60日均量 = 162%（C级，行情商数据）
   - 北向近30日净流入 +28 亿（A级，陆股通披露）
   - 相对全A溢价率历史分位 6%（C级，券商测算）
   ...（其余五个维度同格式）
   ```

### Phase 1 — 六维度分别打分

**目标**：按 1-5 分标准给每个维度打分，附核心论据（≥1 条/维度）。

**交付物**：
1. **维度一 板块轮动信号**（阈值：<60%价值洼地 / >150%热点确认 / 机构持仓连续两季增持 / 溢价率<10%分位极端低配）：
   - 5 分：2+ 强信号叠加
   - 4 分：1 强信号 + 1 中信号
   - 3 分：中性
   - ≤2 分：利空信号
2. **维度二 政策环境**（四级量化表：国家级战略 +3~+5 / 行业准入 +1~+3 / 监管收紧 -2~-4 / 处罚 -1~-3）：
   - 5 分：政策总基调支持 ≥+4
   - 3 分：中性
   - ≤2 分：监管收紧
3. **维度三 外部竞争与国产替代**（产业链位置评估：核心零部件<30%国产化=国产替代加速期 / 中游制造30-60%=黄金成长期 / 下游>60%=成熟期）：
   - 5 分：<30% 且技术差距 >3年（加速替代窗口）
   - 3 分：黄金成长期
   - ≤2 分：行业成熟期或全球 CR5 集中度过高
4. **维度四 技术跃迁**（技术收敛期重仓龙头 / 扩散期分散配置 / 探索期小仓位博弈）
5. **维度五 下游终端市场**（终端规模增速/库存周期/价格传导/进口替代空间）
6. **维度六 公募基金配置与估值水位**（绝对PE <30%分位低估 / 相对溢价率<10%极端低配 / PEG<0.5显著低估）

### Phase 2 — 综合评分卡与配置建议

**目标**：汇总六维度得分生成综合分，并映射配置建议（超配/标配/低配）。

**交付物**：
1. **综合评分卡模板**（六维度+综合）：
   ```
   | 维度 | 当前状态 | 评分(1-5) | 核心论据 |
   |------|---------|----------|---------|
   | 板块轮动信号 | | | |
   | 政策环境 | | | |
   | 外部竞争 | | | |
   | 技术跃迁 | | | |
   | 下游市场 | | | |
   | 基金与估值 | | | |
   | 综合评分 | | | |
   ```
2. **评分→配置建议映射**：
   ```
   综合 ≥4.0 → 超配
   综合 3.0-3.99 → 标配
   综合 2.5-2.99 → 标配(谨慎)
   综合 <2.5 → 低配
   ```

### Phase 3 — 输出报告 + 关键跟踪指标

**目标**：生成完整六维度分析报告，包含综合评分、配置建议、核心投资逻辑、风险点、跟踪指标清单。

**交付物**：
1. **输出要求五项必备**：
   1. 板块综合评分（1-5 分）
   2. 板块配置建议（超配/标配/低配）
   3. 核心投资逻辑（3-5 条）
   4. 关键风险点（2-3 条）
   5. 重点跟踪指标清单（含阈值，如成交量/60日均量 <60%）

## 四、陷阱与经验教训（**至少 6 条，基于实战提炼，禁止空话**）

| # | 陷阱 | 后果 | 规避 |
|---|------|-----|-----|
| 1 | 跳过数据收集直接给分（拍脑袋） | 评分无依据，置信度 N/D | Phase 0 强制每维度 ≥2 条证据 + 来源等级；无证据的维度评分强制 null 或标注 N/D |
| 2 | 政策信号不加权（总理讲话与部委通知同权重） | 政策维度严重失真 | Phase 1 强制按四级量化表（国家级 +3~+5 / 部委 +1~+3 / 监管收紧 -2~-4 / 处罚 -1~-3）打分，禁止一刀切 |
| 3 | 技术阶段判断与投资策略不匹配 | 技术探索期重仓 → 高风险被套 | §三 Phase 1 技术跃迁维度强制按「收敛重仓/扩散分散/探索小仓」三段对应，禁止探索期重仓 |
| 4 | 估值维度只用绝对 PE 不看溢价率和 PEG | 高成长板块被误判高估 | 估值需三维度综合（绝对 PE 历史分位 + 相对全 A 溢价率 + PEG 三者取最低分决定估值水位得分） |
| 5 | 综合六维得分用等权平均但忽略轮动信号前置权重 | 轮动「热点确认」板块被估值单项拉低 | 综合分可加 0.5 调整项（轮动信号≥4分时），但需在综合评分卡「核心论据」明确标注调整 |
| 6 | 缺少跟踪指标清单，无法事后验证结论对错 | Skill 沦为一次性报告，无迭代闭环 | Phase 3 强制输出重点跟踪指标（至少 5 项）并含可操作阈值（如「成交量/60日均量跌破 60% 信号失效」） |
| 7 | 国产化率阈值混用行业差异（医药 vs 半导体） | 30% 国产化率对医药是高对半导体是低 | Phase 1 竞争维度按行业调整国产化率阈值基准：半导体 <40% 算加速期；创新药 <20% 算加速期 |
| 8 | 六维中有效维度 < 60%（缺 >3 维）仍强行输出超配/高配建议 | 结论依据不足；后续跟踪验证无法归因，用户误判导致亏损 | Phase 2 生成综合配置建议前加关卡：有效维度 < 60% → 综合分强制 null + 建议栏强制为「观望 / 等待进一步数据」，且在核心论据首条显式标注「本报告数据覆盖不足（仅 X/6 维度有效），结论置信度降级，建议不作为买卖依据」 |
