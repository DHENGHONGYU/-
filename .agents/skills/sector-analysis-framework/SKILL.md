# 板块分析框架 (Sector Analysis Framework)

> 版本：v1.0 | 日期：2026-06-01 | 基于 V6 v4.3 体系校验 | 对应 skills/SKILL-N
> 本框架为 V6 v4.3 模型的行业层面支撑模块。在个股 L0 STEEP 和 L2 竞品分析中，板块结论作为宏观前提输入。

## 核心目标

建立标准化的六维度板块分析体系，为选股决策提供行业层面的系统性评估。

## 六维度分析框架

### 维度一：板块轮动信号分析

**核心指标：**
1. **成交量信号**
   - 当前成交量 vs 60日均量比率
   - 阈值：<60% 为价值洼地信号；>150% 为热点确认

2. **机构持仓变动**
   - 公募基金季度持仓变化
   - 北向资金/主力资金流向
   - 阈值：连续两季度增持为加仓信号

3. **板块相对强弱**
   - 相对全A溢价率历史分位
   - 阈值：<10%分位为极端低配，具备配置价值

### 维度二：政策环境分析

**政策信号量化赋值：**

| 信号类型 | 权重 | 量化判断标准 |
|---------|------|-------------|
| 国家级战略文件 | +3~+5 | 总理报告→+5；部委规章→+3；政策吹风→+1 |
| 行业准入/支持政策 | +1~+3 | 纳入支持目录→+2；补贴落地→+3 |
| 监管收紧消息 | -2~-4 | 新赛道首次纳入监管→-4；常规扩围→-2 |
| 处罚/整顿 | -1~-3 | 单一公司事件→-1；全行业整顿→-3 |

**分析要点：**
- 政策总基调：支持 vs 控费
- 准入制度变迁
- 不利政策监测红线

### 维度三：外部竞争态势与国产替代

**产业链位置评估：**

| 环节 | 国产化率 | 技术差距 | 投资阶段判断 |
|------|---------|---------|-------------|
| 核心零部件 | <30% | 3-5年 | 国产替代加速期 |
| 中游制造 | 30-60% | 1-2年 | 黄金成长期 |
| 下游应用 | >60% | 已超越 | 行业成熟期 |

**竞争格局观察点：**
- 全球CR5集中度
- 国内龙头市占率
- 技术路线收敛度

### 维度四：技术跃迁分析

**技术成熟度矩阵：**

| 技术阶段 | 特征 | 投资策略 |
|---------|------|---------|
| 技术收敛期 | 路线明确，商业化验证 | 重仓龙头 |
| 技术扩散期 | 多路径并行，快速迭代 | 分散配置 |
| 技术探索期 | 概念验证，路线未定 | 小仓位博弈 |

### 维度五：下游终端市场分析

**需求端分析框架：**
1. 终端市场规模与增速
2. 库存周期定位（主动补库/被动补库/主动去库/被动去库）
3. 价格传导机制
4. 进口替代空间

### 维度六：公募基金配置与估值水位

**估值评估体系：**

| 估值维度 | 计算方法 | 历史分位判断 |
|---------|---------|-------------|
| 绝对PE | TTM市盈率 | <30%分位为低估 |
| 相对溢价率 | 板块PE/全APE | <10%分位为极端低配 |
| PEG | PE/净利润增速 | <0.5为显著低估 |

## 综合评分卡

```
六维度打分卡模板：

| 维度 | 当前状态 | 评分(1-5) | 核心论据 |
|------|---------|----------|---------|
| 板块轮动信号 | | | |
| 政策环境 | | | |
| 外部竞争 | | | |
| 技术跃迁 | | | |
| 下游市场 | | | |
| 基金与估值 | | | |
| 综合评分 | | | |
```

**评分标准：**
- 5分：极强利好/历史极端低位
- 4分：明显利好/具备配置价值
- 3分：中性/观望
- 2分：偏空/谨慎
- 1分：利空/回避

## 输出要求

完成六维度分析后，必须给出：
1. 板块综合评分（1-5分）
2. 板块配置建议（超配/标配/低配）
3. 核心投资逻辑（3-5条）
4. 关键风险点（2-3条）
5. 重点跟踪指标清单

## 使用示例

当用户要求"分析半导体板块"时：
1. 调用本框架执行六维度分析
2. 填写评分卡各维度得分
3. 计算综合评分
4. 给出配置建议和跟踪指标
