# 行业评分估值映射 (Industry Score Mapping)

## 核心功能

当对个股进行 V6 分析时：
1. **自动检索**：按个股代码/业务关键词匹配所属行业
2. **提取评分**：从7份预制的行业 SKILL 分析报告中提取 SKILL-C（四维评级）和 SKILL-N（六维板块）评分
3. **校准关联度**：根据个股与行业的关系强度（核心标的/强关联/中等关联/弱关联）校准得分
4. **注入V6模型**：作为新增 L-1 层参与综合合成

## 匹配流程

```
个股代码/名称/主营业务
    │
    ▼
┌──────────────────┐
│ 第一步：检索核心标的列表      │ → 精确匹配
│ （行业报告中列出的标的）      │ → 关联度=1.0
└──────────────────┘
    │ 无匹配
    ▼
┌──────────────────┐
│ 第二步：关键词匹配             │ → 业务关键词对应行业
│ 光模块→CoWoS/芯片设计         │ → 关联度=0.5~0.9
│ 创新药/CXO→创新药              │
│ AI/云/社交→AI应用及平台        │
└──────────────────┘
    │ 无匹配
    ▼
┌──────────────────┐
│ 第三步：不在覆盖范围内         │ → 标注"无行业报告"
│                               │ → L-1不纳入
└──────────────────┘
```

## L-1 评分公式

```
L-1得分 = SKILL-C总分 × 关联度系数 + SKILL-N额外加分

SKILL-N额外加分：极度超配+0.30 / 超配+0.15 / 标配+0.00
```
