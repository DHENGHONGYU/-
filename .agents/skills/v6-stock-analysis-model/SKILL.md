# V6股票分析模型 (V6 Stock Analysis Model) — v4.3.2

> **版本**: v4.3.2 | **日期**: 2026-08-21 | **校验基准**: FinSightV9 code_version 2.0.0-rc.1
> **任务性质**: SOP 执行（V6 L-1~L8 分层递进式深度个股分析编排），允许输出完整分析报告与评分对象，禁止给缺失层填默认分、禁止综合分由 LLM 直接输出、禁止绕过置信度标注体系、禁止使用未来函数（PIT违规）
> **输出格式**: 阶段化 SOP 矩阵 + L-1~L8 逐层评分（含0-5分+置信度+证据链）+ 综合评估表（评级/目标价区间/置信度）+ 完整16章节 Markdown 报告

## 一、触发条件（Invoke When · RULE-TPL 三标签标注：显式触发 / 脚本/审计触发 / 设计/协议触发）

- **显式触发 1**：用户明确要求「V6深度分析」「个股深度研究」「V6模型」「L-1~L8分析」「生成价值分析报告」「equity research report」；或用户在 V6 深度分析页面（`/analysis/v6-stock-report`）选择/输入标的并点击「开始深度分析」或「重新生成报告」
- **显式触发 2**：公司发布年报/季报（含业绩快报/预告）需要基于新财务数据刷新 L3/L4/L8 层结论；或用户上传个股的新补充资料（调研纪要/专家访谈/订单公告/行业报告 txt/md/json）；或用户要求导出专业 Word 格式报告（联动 `v6-docx-output` 上游）
- **脚本/审计触发 3**：距上次完整 V6 报告超过 7 天、或核心跟踪指标（§六核心跟踪指标体系）触发临界信号触发时效刷新；或 `industry-score` / `industry-score-mapping` 输出更新，L-1 层行业评分估值发生变化触发重算
- **脚本/审计触发 4**：`npm run audit:skill-coverage` 报 V6 模型注册表漂移；或 vitest 中 V6 报告快照断言不通过 / 置信度考核体系用例 FAIL；或 `npm run tsc:prod` 报 V6 类型不一致
- **设计/协议触发 5**：v4.1/v4.2/v4.3 模型版本升级（持股人数八级筹码体系 / 置信度量化考核 / IPC 业绩兑现临界点三维框架）后存量报告重评；L-1~L8 层次结构/权重公式/置信度考核表版本变更后补算兼容；V6 报告 16 章节模板扩展

**不触发场景**（减少误激活，至少 2 条）：
- 纯行业层面的七维评分（走 `industry-score`）
- 个股九维智能评分快速版（走 `intelligent-score`，不执行完整 L-1~L8 深度分析）
- 纯六维度板块轮动信号分析（走 `sector-analysis-framework`）

**协作 Skill（链式调用，至少 1~3 个）**：
- `industry-score-mapping`：L-1 层行业评分估值自动注入（SKILL-C/SKILL-N + 关联度）
- `valuation-financial-analysis`：L3 财务/估值层确定性指标计算（财务比率/PEG/DCF/三情景目标价）
- `intelligent-score`：九维评分结果作为 V6 各层量化参考与交叉验证
- `v6-docx-output`：本 Skill 输出的 16 章节 Markdown 报告作为 Word 导出来源
- `audit:skill-coverage`：完成后核验注册完整性

## 三、阶段化 SOP（按 Phase 0~N 组织，**每阶段必写目标 + 交付物清单 + 代码/文档模板**）

### Phase 0 — 数据准备与阻断级检查（防未来函数 + 数据血缘标注）

**目标**：在启动任何 LLM 推理前，先锁定"Point-in-time 快照"和"阻断级数据完整性"，杜绝未来函数和编造数据。

**交付物**：
1. **PIT 快照记录**（分析基准日 + 每个指标的生效时点）：
   ```
   分析基准日：2026-08-21
   L3财务数据时点：2026-Q1季报（生效2026-04-28），禁止使用2026-Q2未披露数据
   L8筹码数据时点：2026-03-31股东人数（生效2026-04-28）
   ```
2. **阻断级缺失清单**（按 §二 1/2/5 标注缺失项，任一项为空直接 FAIL）
3. **每层输入数据血缘表**（指标→来源→等级→生效时点，与 §六置信度考核表对齐）

### Phase 1 — L-1 行业评分估值注入（调用 industry-score-mapping）

**目标**：在 L0~L8 之前，先完成行业维度定位，为后续各层提供赛道β基准。

**交付物**：
1. **行业归属判定记录**：精确代码匹配 → 业务关键词匹配 → 关联度系数（1.0/0.9/0.7/0.5）
2. **SKILL-C 四维评级明细**（政策/技术/资金/运营 + 证据）+ SKILL-N 六维板块评分
3. **L-1 综合得分**（公式：SKILL-C加权 × 关联度 + SKILL-N额外加分）+ 置信度标注

### Phase 2 — L0~L2 定性层执行（宏观+护城河+竞品，LLM + 强制留痕）

**目标**：执行 STEEP 宏观扫描、护城河类型识别、竞品对比矩阵，所有结论**必须引用证据+标注置信度**，禁止空泛定性。

**交付物**：
1. **L0 STEEP 评分表**：S/T/E/E/P 五维度各子项打分（0-10）→ 均值/2 → 层得分（0-5）+ STEEP 子维度详细评分指引对齐
2. **L1 护城河类型识别矩阵**：5类护城河×4条标准打勾 → 强度（极高/高/中/弱/无）→ 层得分 + 证据引用（专利/NRR/规模效应等）
3. **L2 竞品对比矩阵**（按业务板块拆分）：技术代差/份额/客户认证三维加减分 → 梯队定位 → 层得分

### Phase 3 — L3 财务与估值 + IPC临界点（确定性层优先程序直算）

**目标**：先执行财务比率/估值倍数/预警信号的确定性计算，再叠加 v4.3 新增的 IPC 三维交叉验证（OCR/MCE/TIMS）。

**交付物**：
1. **L3a 财务评分表**（Rubric：营收/盈利/现金流/订单 四维各 1-5 分）+ 红黄预警信号标注（红色触发即降1分）
2. **L3b 估值评分表**（PEG/行业PE基准/机构目标价交叉验证）+ §六估值行业基准库对齐
3. **L3c IPC 业绩兑现临界点判定**（v4.3 核心新增）：
   - OCR 在手订单覆盖率（≥2.5x=5分 分级）
   - MCE 0-1事件驱动 TAM 扩大指数（≥10x=5分 + 8类事件类型库匹配 + 时效性衰减）
   - TIMS 技术迭代×市占率矩阵（5×5交叉矩阵星级）
   - IPC 综合 = OCR×0.35 + MCE×0.30 + TIMS×0.35 → 阶段（已突破/最佳击球区/前夜/遥远/未到）→ L3加分（+1.0/-1.0）

### Phase 4 — L4~L7 情景与成长层（情景推演 + T-M + Hype + 第二曲线）

**目标**：构建三情景概率加权推导目标价，定位技术/市场成熟度象限、Hype周期阶段，以及第二曲线生命阶段诊断。

**交付物**：
1. **L4 情景推演报告**：上行（20-30%）/基准（50-60%）/下行（15-25%）三情景净利×PE → 概率加权合理价 → 目标价区间上下沿 → 收益比公式计算
2. **L5 T-M矩阵**：技术成熟度（0-100）× 市场成熟度（0-100）→ 象限定位 → 策略建议 → 层得分
3. **L6 Hype Cycle 阶段**：Gartner 五阶段匹配 → 投资策略 → 层得分
4. **L7 第二曲线分析**：第一曲线（安全垫）+ 第二曲线（弹性）识别 → 生命阶段诊断（孵化/爆发/成长前期/后期/成熟）→ 催化剂★评级 → 层得分

### Phase 5 — L8 技术筹码 + 八级筹码变化度（v4.1 核心指标）

**目标**：先计算量价/资金确定性指标，再执行 v4.1 新增的八级筹码变化度体系（SCD→PCH→AII→博弈矩阵→RSI→CCS→DIV→CSR）。

**交付物**：
1. **L8a 量价因子评分表**：均线/MACD/布林带 + 量价关系 + 筹码分布 → 评分影响
2. **L8b 资金面评分表**：北向/主力/融资余额/机构调研 → 评分影响
3. **L8c 八级筹码变化度体系**（v4.1 核心）：
   - SCD 持股人数变化率（±10% 阈值）
   - PCH 人均持股变化（同向/背离判断）
   - AII 庄家吸筹强度（>3.0 超强吸筹）
   - 博弈态势矩阵（6 种形态策略建议）
   - RSI 散户游资辨识度（±15% 阈值）
   - CCS 筹码锁定-分散周期（连续2-4期方向）
   - DIV 集中度-股价背离度（±5% 阈值）
   - CSR 筹码系统性风险预警（>200% 极高风险）
   - 八级综合评分 Rubric（+2.0 ~ -2.0）

### Phase 6 — 置信度全链路标注（v4.2 升级，每层+指标强制标注）

**目标**：对 Phase 1-5 所有层得分和核心指标，按 §六置信度考核体系的八级流程完整标注。

**交付物**：
1. **每层指标置信度标注**（格式对齐 §六示例1-4）：
   ```
   [营收增长率 5分 ★★★★★] 来源：2025年报(B级)×2期 + Wind一致预期(C级)
   证据链：2024营收+21.8%，2025营收+23.5%(经审计) → 连续高增确认
   ```
2. **层级置信度聚合**（指标加权 → 星级映射：5★/4★/3.5★/2★/1★/N/D）
3. **综合置信度**（层级加权 → 报告签发判定：≥4★可签发 / 3.5★可签发待补充 / ≤2.5★降级或不可签发）

### Phase 7 — 综合合成 + 16章节报告输出

**目标**：按权重表合成综合分，映射评级与目标价，生成符合 §六输出报告结构的 16 章节完整 Markdown。

**交付物**：
1. **综合评估表**（11 项权重对齐 §六权重表 v4.0）：
   | 层 | 维度 | 权重 | 得分 | 置信度 |
   |----|------|:---:|:---:|:---:|
   | L-1 | 行业评分估值 | 10% | X.X | ★★★★ |
   | ... | ... | ... | ... | ... |
   | → **综合分** | | 100% | **X.XX** | **★★★★☆** |
2. **评级映射**（§六评级映射表：≥4.5买入 / 4.0-4.49增持 / 3.0-3.99中性 / 2.0-2.99减持 / <2.0卖出）+ 建议仓位
3. **目标价区间**（概率加权合理价 → 区间下沿=基准上沿，区间上沿=上行下沿）+ 收益比
4. **重分层级冗余校验**（宏观/竞争力/财务估值/市场时机 四层汇总，差值>1分需标注说明）
5. **16 章节 Markdown 报告**（结构严格对齐 §六输出报告结构 1-16 项）

## 四、陷阱与经验教训（**至少 6 条，基于实战提炼，禁止空话**）

| # | 陷阱 | 后果 | 规避 |
|---|------|-----|-----|
| 1 | L3 确定性层用 LLM "算"财务比率，而非程序直算 | 计算错误不可复现 + 置信度虚高 | Phase 3 明确：财务比率/PEG/筹码指标 **必须程序直算**，LLM 只负责解释和异常标注 |
| 2 | PIT 违规：用 Q2 未披露数据评估 Q1 时点评级 | 回测收益虚高，实盘完全失效 | Phase 0 强制：每个指标标注"生效时点"，回测时只取生效时点前的数据 |
| 3 | L-1 层未调用 industry-score-mapping，手动拍行业分 | 7 行业评分不一致 + SKILL-C/N 四端漂移 | Phase 1 **铁律**：L-1 层必须走 Skill 链式调用，禁止手工填分；映射失败则标注关联度=0.5并降置信度 |
| 4 | IPC 临界点 OCR/MCE/TIMS 三维只取一维，未交叉验证 | 单一维度信号误判率高（如订单披露不规律） | Phase 3 强制：IPC = OCR×0.35 + MCE×0.30 + TIMS×0.35，三维**缺一不可**，缺项权重转给其他两项但必须标注 |
| 5 | 置信度只给最终报告标，每层/指标不标 | 无法追溯哪个环节数据质量差，报告降级无依据 | Phase 6 **强制格式**：每个核心指标后紧跟 `[X分 ★★★] 来源：XX(B级)`，禁止聚合后补标 |
| 6 | 筹码变化度只看 SCD 一期数据，不看连续 2-4 期 CCS 周期 | 误判：一期 SCD 为负可能只是偶发，而非吸筹周期 | Phase 5 强制：CCS 七级指标必须基于连续 2-4 期方向，单期 SCD 只进 RSI/DIV 不单独出周期结论 |
| 7 | 综合分由 LLM 直接输出，不按权重表逐层合成 | 权重漂移 + 不可复现 + 黑箱评分 | Phase 7 **铁律**：综合分必须由 Σ(层得分×权重) **程序直算**，LLM 不得输出 overallScore 字段 |
| 8 | 红黄预警信号只标注不扣分 | 预警形同虚设，财务地雷股评分虚高 | Phase 3 明确：红色预警**任一触发即 L3 财务层 -1.0 分**，黄色预警标注但不强制扣，两种均需在 §六14三大核心风险中列明 |
